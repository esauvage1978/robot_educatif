Conseils pour commander

Vérifier la date de livraison affichée

Sur Amazon, vérifiez la date de livraison estimée affichée au moment de la commande, privilégiez les vendeurs « Expédié par Amazon », plus fiables, et évitez les vendeurs tiers aux délais longs. Surtout, commandez le plus tôt possible pour éviter les ruptures de stock et être sûr de recevoir le robot avant les fêtes.

Plan B si stock limité :

Si le robot n'arrive pas à temps, le plan B ne gâche pas la surprise. Vous pouvez glisser une carte Amazon du montant du robot visé dans une enveloppe personnalisée (« Ton robot arrive ! Choisis-le ensemble sur Amazon le 26 »), imprimer une photo du robot avec le message « Ce robot t'attend ! Commande passée, livraison prochainement », ou offrir un starter kit avec le livre « Scratch pour les kids » et la mention « Le robot arrive dans quelques jours ».

Astuce : emballez le bon ou le livre dans une grande boîte remplie de papier froissé, pour garder l'effet « gros cadeau ».
