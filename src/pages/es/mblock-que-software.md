Abres **mBlock** por primera vez y no sabes si **instalarlo**, abrirlo **en el navegador** o pasar ya a **Python**. Esta página compara las tres puertas, con palabras llanas, según el ordenador, los derechos de administrador y el robot (**mBot**, **mBot2**).

La aplicación, la versión web y el modo Python no son equivalentes. Depende del robot, de los derechos de administrador y del Bluetooth.

| | Aplicación | mBlock Web | Python en mBlock |
| --- | --- | --- | --- |
| Conviene si | conectas un robot, actualizas el firmware, quieres estabilidad | el colegio prohíbe instalar, o haces una demo corta | los bloques ya están claros y pasas a la sintaxis |
| Límites | descarga y a veces derechos de administrador | Bluetooth más inestable | depende del modelo (mBot2, CyberPi) y de la versión |

## 1. La aplicación

Prefiérela para USB o Bluetooth, para cargar el programa en la placa y para el firmware. Sin USB, el firmware suele desaconsejarse: la nota del modelo está en [Makeblock Support](https://support.makeblock.com/). Después: [primeros pasos](/es/primeros-pasos-mblock-5/).

## 2. El navegador

Útil en un ordenador que no deja instalar, o para mostrar los bloques sin sacar el robot. Para un robot físico desde el navegador suele hacer falta **mLink**. Si se corta: [problemas de Bluetooth](/es/mblock-bluetooth-solucion/).

## 3. Python

Llega después de los bloques. El acceso al texto y las funciones cambian con el modelo y la versión. Prueba en un solo robot antes de un grupo. Contexto del hardware: [mBot y mBot2](/es/mbot-vs-mbot2/).

## 4. Bloques del robot

Sin el dispositivo correcto, los bloques de motores y sensores no aparecen. Procedimiento: [instalar los bloques mBot](/es/instalar-bloques-mbot/).

## 5. Scratch y mBlock

Scratch ([scratch.mit.edu](https://scratch.mit.edu/)) sirve para proyectos en pantalla. mBlock sirve para el ecosistema Makeblock. Con un robot Makeblock se empieza por mBlock.

## Preguntas

**¿Elijo solo uno?** No. Aplicación cuando el robot está en la mesa, web en los ordenadores bloqueados, Python cuando los bloques se entienden.

**¿Live o carga?** En Live pruebas en tiempo real mientras dura el enlace. La carga mete el programa en el robot, que luego arranca sin cable.

**¿mBlock 5 y mBlock 3?** Las guías recientes de este sitio parten de mBlock 5. Un tutorial muy viejo puede tener otros menús.

**¿«Minecraft mblock» es mBlock?** No. Minecraft es un juego. mBlock es el software de Makeblock. Si la búsqueda falla, añade Makeblock o mBot.

Esta página no enlaza una ficha de Amazon.es: los ASIN franceses no se dan por los mismos productos en España. Software oficial: [mblock.cc](https://www.mblock.cc/) y [ide.mblock.cc](https://ide.mblock.cc/).

**Para quedarse con ello:** aplicación en el ordenador del proyecto, web en los ordenadores bloqueados, Python solo cuando la lógica de los bloques es sólida. Luego [mBlock o Scratch](/es/mblock-vs-scratch/).
