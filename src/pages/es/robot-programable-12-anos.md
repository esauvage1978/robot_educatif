**A los 12 años elige primero el tipo de proyecto y después el kit.** A menudo es 1.º de ESO. Tres caminos honestos:

- Un robot que se mueve, ahora en bloques y luego en Python: **mBot2**.
- Cablear una placa y escribir C de Arduino: **ELEGOO Smart Robot Car V4.0**, los pasos finos contigo. El fabricante indica 13+.
- Linux, Python y un ordenador que se reutiliza: **Raspberry Pi 5**, que no es un robot hasta que añades chasis y motores.

Un niño de 12 sigue un tutorial, se queda media hora con un problema y le importa un proyecto terminado. Los controladores, la alimentación y los cables flojos siguen siendo tropiezos. Es normal. No es un motivo para comprar el kit más complicado del catálogo.

## Qué buscar

Un sistema abierto gana a un juguete cerrado: tutoriales, recambios, un lenguaje que puede volver a encontrar. Cuenta los extras. Una Pi pide alimentación y microSD; convertirla en robot es una segunda compra. Un mBot2 es un robot el primer día.

No hemos vuelto a probar cada anuncio para esta página. Las listas de sensores siguen las fichas de los fabricantes ya usadas en la comparativa (revisión del 21 de octubre de 2026). En Amazon.es el mBot2 se abre como búsqueda por nombre, no como ficha de producto dada por buena.

## Cómo saber que funciona

mBot2: el robot se mueve con un programa de bloques y con un ejemplo corto de Python. ELEGOO: el coche se mueve con un sketch de ejemplo, corriente cortada mientras cambias cables. Pi: arranca el escritorio y edita un archivo Python. Solo entonces se habla de motores.

## Preguntas

### ¿12 años es demasiado pronto para Arduino?

No para un kit con manual, si un adulto lleva el cableado. Demasiado pronto es una placa de pruebas suelta sin un objetivo.

### ¿mBot2 y Raspberry Pi a la vez?

Uno de los dos. Dos plataformas son dos configuraciones y un robot que no se termina. La segunda se añade cuando la primera se usa de verdad.

## Preguntas frecuentes

### ¿Qué robot programable a los 12 años primero?
**mBot2** para bloques y luego Python. **ELEGOO** para Arduino con un adulto. **Raspberry Pi 5** si quieren Linux y proyectos largos.
