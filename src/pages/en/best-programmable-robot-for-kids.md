Around **8–10**, the **Makeblock mBot** (about **£85–110** on <a href="/go/az-gb-b5d4d0b7cd/" rel="sponsored nofollow noopener">Amazon UK</a>, check listing) remains the most documented reference on this site; from **10–14**, the **mBot2** (about **£130–170**) adds Python and advanced sensors. A **programmable** robot is **not** an **AI** toy: it runs **your** program, without a built-in chat assistant.

## Remote-controlled, programmable, autonomous, educational or “AI”?

| Type | What the child does | Example | Pitfall |
|------|---------------------|---------|---------|
| **Remote-controlled** | Drives in real time (arrows, gamepad) | Basic RC car | Little programming |
| **Programmable** | Writes a sequence (blocks or code) | mBot, Botley 2.0, LEGO SPIKE | Needs software + sometimes an adult |
| **Autonomous (sensors)** | The program reacts alone (distance, line) | mBot obstacle avoidance | Confused with “intelligence” |
| **Educational robot** | Pedagogical kit + resources | Makeblock, LEGO Education | Variable quality among clones |
| **Marketing “AI”** | App or cloud “smart” features | Some connected toys | Often **≠** structured programming |

## 6. Troubleshooting after unboxing (mBot / mBot2)

Most issues appear **before** the first successful program. Keep this checklist for Christmas morning.

| Symptom | Likely cause | What to do |
|---------|--------------|------------|
| Robot does not move | Program not uploaded, flat batteries or Bluetooth drop | Check the board LED, replace or recharge batteries, click **Connect** in mBlock and retry |
| mBlock cannot see the robot | Missing USB/Bluetooth driver, wrong link mode | Follow [install mBlock](/en/install-mblock-5-windows/), use USB for the first session, then [Bluetooth troubleshooting](/en/mblock-bluetooth-troubleshooting/) |
| Robot drives backwards | Motor cables swapped or chassis orientation | Recheck the build (15–30 min); compare with Makeblock’s guide |
| Botley misses the line | Floor too shiny, dirty sensors | Clean the base, test on a wide black line on matte white floor |
| ELEGOO sketch fails | Wrong board or COM port in **Arduino IDE** | Select UNO and the correct serial port; follow the in-box tutorial |

## FAQ

### Which programmable robot by age?
Around **5**, screen-free; **8**, mBot or blocks kit; **10**, mBot2; **12+**, mBot2, Arduino or Raspberry Pi — open the matching age guide.

### Do we need Python from day one?
No. Blocks suffice first; Python often from **10–12** when logic structures click.

### Realistic Christmas budget?
Robot **plus** batteries and storage — always check the live listing.

### mBot or mBot2?
**mBot** for first robotics; **mBot2** for Python and longevity — [mBot vs mBot2](/en/mbot-vs-mbot2/).
