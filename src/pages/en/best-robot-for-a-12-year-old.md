**At 12, choose the kind of project, then the kit.** In England this is often Year 7, the start of secondary school; in the US, 7th grade. Three honest paths:

- They want a robot that moves, in blocks now and Python next: **mBot2**.
- They want to wire a board and write Arduino C: **ELEGOO Smart Robot Car V4.0**, with you for the fiddly steps. The maker rates it 13+.
- They want Linux, Python and a computer they can reuse: **Raspberry Pi 5**, which is not a robot until you add parts.

A 12-year-old can follow a tutorial, stay with a problem for half an hour, and care about a finished project. They still get stuck on drivers, power and loose wires. That is normal. It is not a reason to buy the most complicated kit in the catalogue.

## What to look for

An open ecosystem beats a closed toy at this age: tutorials, spare parts, a language they might meet again. Count the extras. A Pi board needs a power supply, a microSD card and, if it is going to be a robot, a chassis and motors that are a second purchase. An mBot2 is a robot on day one.

## How to know it works

mBot2: the robot moves from a block program, then from a short Python example in mBlock. ELEGOO: the car moves from an example sketch after the wiring matches the manual, with the power off while you change cables. Pi: the desktop boots, they edit a Python file, and only then do you talk about motors.

## Questions parents ask

### Is 12 too young for Arduino?

Not for a kit with a manual, if an adult owns the wiring session. It is too young to hand them a loose breadboard and a pile of sensors with no goal.

### Should we buy mBot2 and a Raspberry Pi?

One of them. Two platforms at once means two setups and a robot that never gets finished. Add the second when the first one is actually used.

## Frequently asked questions

### Which coding robot for a 12-year-old first?
**mBot2** if they want a ready robot with blocks then Python. An **ELEGOO Arduino car** if they want wiring and C++ with an adult. A **Raspberry Pi 5** if they want Linux and longer projects (add a chassis later).

### Do they need to know how to code already?
No. Blocks are fine at the start. Plan adult help for the first software install.
