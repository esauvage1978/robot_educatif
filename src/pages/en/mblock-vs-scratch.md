This page compares Scratch and mBlock as languages and environments. It is not the page for downloading or opening the IDE. For that, use [mBlock online (ide.mblock.cc)](/en/mblock-online-no-install/), [download mBlock 5](/en/download-mblock-5-free/), or the [Makeblock software comparison](/en/mblock-software-which-to-choose/). Scratch online is enough when there is no robot. mBlock adds the Makeblock blocks, including the mBot.

Both are block-based environments for children and beginners. Scratch is for games, animations and stories on a computer. mBlock sends the same kind of blocks to a robot or a board. The useful difference is the setting: school, home, or robotics.

## Quick summary: mBlock vs Scratch

| Criterion | Scratch | mBlock |
|---------|---------|--------|
| **Main use** | Video games, animations, stories | Robotics, IoT, electronics projects |
| **Hardware** | 100% software (computer only) | Compatible with robots (mBot, Arduino, micro:bit…) |
| **Target age** | 6–14 years | 8–16 years |
| **Community** | Very large (public projects on scratch.mit.edu) | Medium, tied to Makeblock robots |
| **Free** | Yes, entirely | Yes, account optional |

| **Code export** | No, blocks only | Yes: Arduino C and Python |
| **Next language** | Python, JavaScript | Arduino C, Python |

In one sentence: Scratch creates games and animations on a computer, and mBlock programs robots and connected objects.

## What is Scratch?

![Scratch logo](/images/logos/scratch-logo.svg)

Scratch is a visual programming language created by the MIT (Massachusetts Institute of Technology) in 2007. Children stack coloured code blocks to build a game, an animation or an interactive story.

It starts in the browser, with no complicated install. The community is very large, public projects on scratch.mit.edu can be opened and remixed. Tutorials, online courses and books are widely available, in many languages. A computer is enough, which suits a school. Typical projects are platform games, quizzes and animated stories.

The limits match that scope. A project stays on screen: Scratch does not, as standard, connect to a robot or a physical sensor. There is no built-in path from blocks to text code, and a project cannot be turned into a real exported app. Complex games also run into performance limits quite quickly.

Scratch fits children aged 6 to 12 who are discovering programming, and it remains usable up to about 14. It is the primary-school tool when the project is a story, a game or an animation, and a computer or tablet is enough. Start with [Scratch at school and at home](/en/scratch-school-home-getting-started/).

## What is mBlock?

![mBlock logo](/images/logos/mblock-logo.svg)

mBlock is the environment from Makeblock, a Chinese educational robotics company. It is based on Scratch, with extra blocks for physical robots such as mBot, Arduino, micro:bit and other boards.

It talks to Makeblock robots (mBot, mBot2), Arduino, micro:bit and CyberPi. Blocks can be exported to Arduino C or Python, so the move toward text is visible. Projects can use Wi-Fi, Bluetooth and connected sensors. The software is free on Windows, Mac, Linux, iOS and Android. Two modes sit side by side: “live”, which tests while the robot stays linked to the computer, and “upload”, which copies the program into the robot so it runs on its own.

The community is smaller than Scratch, and fewer projects are shared. Documentation is sometimes in English, with fewer resources in other languages. Using the whole of mBlock means having hardware. The install can be picky: drivers, Bluetooth, USB.

mBlock is for ages 8 to 16 when the point is to program something that moves. In secondary technology lessons and robotics clubs it covers robots, sensors, LEDs and motors, and it prepares embedded programming on Arduino. To install and start: [Install mBlock 5 on Windows](/en/install-mblock-5-windows/), [First steps with mBlock 5](/en/first-steps-mblock-5/), [mBot: my first educational robot](/en/mbot-my-first-educational-robot/) and [Programmable robot with Scratch: which to choose?](/robot-programmable-scratch-lequel-choisir/).

## Detailed comparison

### 1. Interface and getting started

Scratch is clean and colourful. The block palette sits on the left, the stage in the centre, the code on the right. A first script takes about five minutes.

mBlock copies that layout on purpose. The palette stays, and hardware extensions add the robot next to the sprites. Allow ten to fifteen minutes, because the robot still has to be connected.

Scratch is the simpler start. mBlock needs a setup stage.

### 2. Possible projects

Scratch covers games (platformer, maze, quiz), animations and cartoons, simulations such as a solar system or an ecosystem, and generative art (fractals, spirographs).

mBlock leaves the screen: a line-following robot, obstacle avoidance, an intrusion detector, an LED matrix, or a small connected project (temperature, weather, home automation).

They are different worlds. Choose by the goal, virtual or physical.

### 3. Learning to program

Scratch teaches the core ideas: loops, conditions, variables, events. The logic is visible without hardware in the way, and children invent their own rules. The tool itself does not prepare a later move to Python or JavaScript. You stay in blocks.

mBlock keeps those ideas and adds sensors and actuators. Export shows how a block becomes C or Python. The code drives a real object, and the natural next step is Arduino C or Python.

mBlock prepares better for more technical programming.

### 4. Required hardware

Scratch needs a computer or a tablet with a web browser, an internet connection or the offline app, and nothing else.

mBlock needs a Windows, Mac or Linux computer, a USB cable (Bluetooth on some kits) and batteries or a power supply. The usual hardware is a Makeblock robot such as the mBot, an Arduino board, or a BBC micro:bit. No UK or US price is given on this page: the French mBot ASIN is not reused as an Amazon.co.uk or Amazon.com listing. Scratch has no hardware cost. mBlock means buying a robot or a board.

### 5. Resources and community

Scratch publishes projects on scratch.mit.edu: they can be opened and remixed. Forums are active, support comes from MIT, and books, courses and MOOCs exist in many languages.

mBlock stays tied to Makeblock products. Official tutorials exist, and their quality varies. Forums are quieter than Arduino or Scratch. Local help is mostly this site and some YouTube channels.

On community size, Scratch is far ahead.

### 6. Progression and lifespan

Scratch is usable from about 6 to 14. After that, the usual next step is Python with pygame, or JavaScript with p5.js. Projects stay available online.

mBlock fits roughly 8 to 16, then Arduino C or Python. Projects are saved locally as .mblock files, or in the cloud.

Code export is what makes mBlock last longer.

## Use cases: when to choose what?

Scratch is the right first contact at 6 to 8, especially with no budget for hardware. It suits a primary school that has computers but no robots, when the priority is a game, a story or visual art, and robotics is not the next step. A Year 4 or Year 5 class meeting algorithms for the first time is that case.

mBlock is the one to use when a robot is already there, or about to be bought, usually from age 8, once a physical project is realistic. It belongs in secondary school and in a robotics club, in a path toward Arduino, and in work with connected sensors or home automation. A Year 7 technology class with mBot kits is the typical example.

The two tools sequence well. Start with Scratch around 6 to 8, and spend one or two years on the logic. Around 8 to 10, mBlock reuses those basics on a robot for another one or two years. From 12, Arduino C or Python moves the work into text code.

## Technical differences

### Available blocks

Scratch has motion for sprites, looks (costumes, speech bubbles, effects), sound (notes and recordings), events (clicks and keys), control (loops and conditions), sensing for the mouse, the microphone and the clock, operators for maths, logic and strings, then variables and lists.

mBlock keeps every one of those blocks. It adds motors (forward, reverse, speed), sensors (ultrasonic, line, light, temperature), actuators (RGB LEDs, buzzer, servos), communication (Bluetooth, Wi-Fi, serial) and extensions for Arduino, micro:bit, CyberPi and AI.

### Execution modes

Scratch runs online, in real time in the browser. The offline app is the exception.

mBlock has three modes. “Live” tests at once, with the robot linked to the computer. “Upload” copies the program into the robot, which then runs without a PC. “Scratch” behaves like Scratch, with no robot.

### Code export

Scratch cannot export. A project can be read only inside Scratch.

mBlock exports Arduino C: you can see the generated code and edit it in the Arduino IDE. Python export is for compatible robots, notably CyberPi and micro:bit. The point is to understand what the block actually does.

Example:

```cpp
// mBlock block: "Move forward at speed 100"
// becomes in Arduino C:
mBot.motor.leftWheel.setSpeed(100);
mBot.motor.rightWheel.setSpeed(100);
```

## Installation and getting started

For Scratch, open [scratch.mit.edu](https://scratch.mit.edu) and click Create. The project starts in the browser. An offline app also exists for Windows, Mac and Linux.

For mBlock, the online editor is at [ide.mblock.cc](https://ide.mblock.cc). For the installed version, download mBlock 5 from [mblock.cc](https://mblock.cc/), follow the wizard, connect the robot by USB or Bluetooth, add its extension (for example “mBot”) and test the connection. The Windows steps are in [Install mBlock 5 on Windows](/en/install-mblock-5-windows/).

## Example projects

### Scratch project: Pong game

```
When green flag clicked
Forever
  If key “space” pressed
    Move paddle by 10 pixels
  If ball touches edge
    Bounce
```

A complete game fits in 20 to 30 blocks and plays in the browser.

### mBlock project: Line-following robot

```
When program starts
Forever
  If left line sensor = black AND right line sensor = white
    Turn left
  Else if right line sensor = black AND left line sensor = white
    Turn right
  Else
    Drive straight
```

The robot then follows a black line on a white background on its own.

## Hardware compatibility

Scratch has no robot that works natively. Unofficial extensions exist, ScratchX and Snap!, but they are rarely reliable.

mBlock recognises the mBot (Makeblock’s wheeled robot), the mBot2 (the advanced version with CyberPi), Codey Rocky, Arduino UNO, Nano and Mega, the BBC micro:bit, the Raspberry Pi Pico, CyberPi used on its own, and Grove sensors from the Seeed Studio ecosystem.

The Makeblock mBot is the usual first robot for mBlock, for about ages 8 to 12. It is programmed in Scratch-style blocks and in Arduino. The blocks are straightforward, and several sensors are already in the box. ## FAQ — mBlock vs Scratch

### Is mBlock harder than Scratch?

Not really. The interface is almost the same. The extra difficulty is connecting the robot (USB, Bluetooth, drivers) and reading the hardware: sensors and motors. Once the link is up, programming is the same kind of work.

### Can you move from Scratch to mBlock easily?

Yes. Someone who knows Scratch finds their way in about 30 minutes. The blocks are the same. Only the hardware part changes.

### Do you need a robot to use mBlock?

No. “Scratch” mode works without a robot, just like Scratch. The main reason to use mBlock is still to program hardware.

### Does mBlock work with LEGO robots?

No. Mindstorms and SPIKE have their own software. For LEGO, use LEGO Education, or an alternative such as EV3 Classroom.

### Is Scratch really free? And mBlock?

Yes. Both are entirely free. Scratch is an MIT project, educational and without ads. mBlock is free for personal and educational use: Makeblock earns money by selling robots, not the software.

### Can you use mBlock offline?

Yes. Once the app is installed, it works without a connection. You can program and upload to the robot even without Wi-Fi.

### Does mBlock replace the Arduino IDE?

No. It complements it. mBlock produces Arduino C that you can export and then edit in the Arduino IDE. It is a bridge, not a replacement.

| **Ease** | Unbeatable | Easy with a little help |

From 6 to 10, for a first contact, start with Scratch. From 8 to 14, with a robot or a robotics project, use mBlock, including from 10 to 14 if the next step is Arduino. A class without hardware stays on Scratch. A robotics club moves to mBlock.

Scratch and mBlock complement each other. Scratch teaches you to think a program through. mBlock applies that thinking to real objects. Depending on whether the goal is creative or technical, one will go further than the other. Start with Scratch, then move to mBlock when robotics becomes the subject.
