**At 14, buy a platform they can reuse, not a closed toy.** In England this is often Year 9; in the US, 9th grade. The interesting projects are concrete: a robot that follows a line with its own code, a camera car, a small weather station, a Python script that talks to a sensor. Arrow remotes and picture cards are the wrong gift. So is a bare electronics assortment if they have never finished a tutorial.

A 14-year-old can search a tutorial, stay stuck for half an hour, and read documentation in English. That last point matters: a lot of the good Arduino and Raspberry Pi material is not translated. Motivation comes from a project they chose, more than from a worksheet.

This guide is too technical under 12. If they are 12 and new to coding, start with the [12-year guide](/en/best-robot-for-a-12-year-old/).

## What to look for

Prefer Arduino, Raspberry Pi or a board with a real Python path (mBot2's CyberPi). You get spare parts, tutorials and a language that exists outside the toy. The languages worth aiming at are Python, C/C++ on Arduino, and JavaScript only if they already care about the web.

Budget for more than the box. A kit is the start. Extra sensors, a proper power supply and a book or a course are separate purchases. Check those prices on the day; do not add a converted euro figure and call it a local total.

## A simple decision

They like building circuits: ELEGOO. They like computers and will accept that a robot comes later: Raspberry Pi 5. They want something that drives across the table this weekend, then a path into Python: mBot2.

## How to know it works

ELEGOO: one example sketch from the manual moves the car, and they can change a speed value. Pi: they boot to the desktop and run a Python file they edited. mBot2: a block program and a short Python example both move the robot. If none of that happens, stop buying more parts and fix the first setup.

## Questions parents ask

### Is a drone or a robot arm a better 14th-birthday gift?

Only after one of the three paths above is going well. A drone adds safety rules and a higher chance of a crash before the first program works.

### Do they need to solder?

Not for these three starter kits. Soldering is a later skill, with supervision, when a project actually needs it.
