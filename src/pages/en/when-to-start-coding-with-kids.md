> **Direct answer (October 2026)** — You can build **logic from ages 4–6** without a screen (tokens, floor paths). **Computer/tablet coding** with **Scratch** (free block language from MIT) fits around **7–9** if the child stays **20–40 minutes** on a task and will **fix** after failure. **Python** (typed text language) often starts around **10–12**, depending on kit and support. The age on the box is not enough: weigh **motivation**, **frustration** and **adult time** for install, save and troubleshooting.

**Coding**, for a child, means giving **precise instructions** to a machine or on-screen character: “move, turn, if you see a wall, back up.” It is not “being good at maths” or “watching YouTube all day.” On this site, [best programmable robots for kids](/en/best-programmable-robot-for-kids/) is the main buying hub by age; [Scratch at school or home](/en/scratch-school-home-getting-started/) is the usual software start.

## Age bands (indicative, not fixed walls)

| Age band | Typical goal | Tools | Useful session | Adult |
| --- | --- | --- | --- | --- |
| **4–6** | Chain 3–5 commands, plan a path | Tokens, **screen-free** robots | 10–20 min | Always nearby |
| **7–9** | Loops, events, one finished project | **Scratch** 3, **mBlock**, block robots | 20–40 min | Help install / save |
| **10–12** | Sensors, multi-session projects | mBot2, intro **Python**, CyberPi | 40–60 min | Present at start |
| **12+** | Data, console, autonomy | Structured Python, **Raspberry Pi**, Arduino C | 1 h+ possible | Weekly check-in |

**Scratch** is a **block** language from **MIT** (Massachusetts Institute of Technology). **mBlock** is Makeblock’s Scratch-like app that drives robots. **Python** is a **text** language the computer reads line by line — often after blocks.

## 1. Four phases in detail

### 4–6: logic before the screen

Unplugged games, **screen-free** robots, little reading. Goal: **decomposition** (“first forward, then turn”), not syntax. See [best robot for a 5-year-old](/en/best-robot-for-a-5-year-old/) and [Matatalab Tale-Bot Pro](/en/matatalab-tale-bot-educational-robot/).

**Expected result**: four commands in order; the child fixes order if the robot misses the target.

### 7–9: blocks and first loops

When they hold **20–40 minutes**, **rephrase** what fails and read short lines, **Scratch** / **mBlock** fit. Start with [Scratch school/home](/en/scratch-school-home-getting-started/) and [the square activity](/en/scratch-activity-square/). Hardware: [8-year guide](/en/best-robot-for-an-8-year-old/), [7-year guide](/en/best-robot-for-a-7-year-old/), [mBlock vs Scratch](/en/mblock-vs-scratch/).

**Expected result**: green-flag start, motion and one loop, shown to someone at home.

### 10–12: sensors, longer projects, text bridge

Multi-sensor robots, multi-session builds, first **Python** on some kits — [mBot vs mBot2](/en/mbot-vs-mbot2/), [10-year guide](/en/best-robot-for-a-10-year-old/), [first mBot program](/en/first-mbot-program/).

**Expected result**: program reacts to a sensor; child explains an “if… then…” rule.

### 12+: autonomy and systems

Structured **Python**, **CyberPi** / **Raspberry Pi** boards, readable console errors — [12-year guide](/en/best-robot-for-a-12-year-old/), [Raspberry Pi 3 getting started](/en/raspberry-pi-3-getting-started/), [CyberPi overview](/en/makeblock-cyberpi-overview/), French Python hub at [/programmation/python/](/programmation/python/) if you read French.

## 2. Readiness signs (any age)

- Accepts changing a guess after failure.
- Can **explain** what the program *should* do before running.
- Tolerates ~5 minutes of update, USB or Bluetooth setup.
- Asks to try again tomorrow instead of quitting for good.

If signs are missing, step back (shorter task, screen-free, ScratchJr on tablet).

## 3. Digital skill ≠ coding

Fast on YouTube or a game does not mean ready to **debug**. Coding needs words: name the bug, split the problem, change **one** thing per test.

## 4. What parents can do (without coding for them)

- **Short, repeated** slots (2 × 30 min / week).
- **One project** with a **demo** at the end — [Scratch guide](/en/scratch-school-home-getting-started/).
- **Questions**, not keyboard takeover: “what if we remove this block?”
- **Save**: Scratch account or `.sb3` on USB — lost project = lost motivation.
- **Setup**: [Install mBlock 5](/en/install-mblock-5-windows/), [Bluetooth troubleshooting](/en/mblock-bluetooth-troubleshooting/), [install mBot blocks](/en/install-mbot-blocks/).

## 6. Troubleshooting when “it doesn’t stick”

| Situation | Common cause | Fix |
| --- | --- | --- |
| Quits after 5 min | Project too big | [Square activity](/en/scratch-activity-square/) or screen-free |
| Wants you to code | Passive screen habit | One question per bug |
| Upset at every error | Fear of “wrong” | Praise the test, not only success |
| Robot still | USB, battery, mBlock | [mBot blocks](/en/install-mbot-blocks/), [Bluetooth](/en/mblock-bluetooth-troubleshooting/) |
| “Want another robot” | Bored or wrong kit | Free Scratch first; [mBot vs LEGO](/en/mbot-vs-lego-robot/) when ready |

## 7. Mini-FAQ

**Six years old, little reading?**  
Tokens, floor paths, [5-year robot guide](/en/best-robot-for-a-5-year-old/); **ScratchJr** on tablet if available.

**School starts Scratch in year 3 — wait?**  
No: short home tasks can prepare; align with [Scratch school/home](/en/scratch-school-home-getting-started/).

**Robot on day one?**  
No: Scratch alone often works **6–12 months**; robots after loops/events — [mBlock vs Scratch](/en/mblock-vs-scratch/).
