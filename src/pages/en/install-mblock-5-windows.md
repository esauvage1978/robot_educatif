**mBlock 5 is free** to download from the official site, [mblock.cc](https://www.mblock.cc/en-us/download/). It is [Makeblock](/en/makeblock-brand/)'s Scratch-based app for coding robots such as the **mBot** and **mBot2**, and it can also switch to Python. This guide takes you through installing it on Windows 10 or 11.

## Before you start

- A Windows 10 or 11 PC with an **administrator** account (or an adult who has one).
- Around **1 GB** of free disk space for the download and the installed app (the installer itself is roughly 380 MB).
- A stable internet connection.

No PC? mBlock also runs in a browser at [ide.mblock.cc](https://ide.mblock.cc/), with the **mLink** helper to connect hardware.

## Step 1: Download the installer

1. Open **[mblock.cc, Download](https://www.mblock.cc/en-us/download/)**.
2. Choose **Windows** and download **mBlock 5**.
3. The `.exe` file lands in your **Downloads** folder.

## Step 2: Run the installer

1. Double-click the `.exe` file.
2. Windows asks **"Do you want to allow this app to make changes?"** (User Account Control): click **Yes**.
3. The installer runs on its own, with a progress bar.
4. When you see **Finish**, mBlock is installed and a shortcut appears on the desktop.

## Step 3: First launch

Open mBlock 5, then pick your device (for example **mBot** or **mBot2**) in the **Devices** panel. You can change the interface language in the app settings.

## Quick fixes

| Problem | What to try |
|---|---|
| The `.exe` won't start | Right-click → **Properties** → **Unblock** if shown; run as administrator; download again. |
| "Windows protected your PC" (SmartScreen) | **More info** → **Run anyway**, only if the file came from mblock.cc. |
| Installation stops with an error | Your antivirus may be blocking it: allow the installer, then retry. |
| No admin rights (school PC) | Ask the IT department, or use the browser version. |
| Robot not detected | Plug it in by USB first; for Bluetooth on mBot, see Makeblock's help pages. |
