## Why the ~€100 band matters

Below **~€50**, kits are often **limited** or toy-like. **Around €85–100**, you reach **classroom-proven** robots: **multiple sensors**, **maintained software**, sometimes a path to **Arduino** (programmable microcontroller board). Above **~€150**, **mBot2** or LEGO sets add features you may not need for a **first** robot.

| Info | Detail |
| --- | --- |
| **Goal** | Pick a **credible** programmable robot under €100 |
| **Audience** | Parents, teachers, gift ages 8–14 |
| **Difficulty** | mBot **easy** build; ELEGOO Car **intermediate** wiring |
| **Time** | 15 min (mBot) to 2 h (ELEGOO Car) first build |
| **Software** | **mBlock 5** (free), **Arduino IDE** (free) |

**Scratch** = free **block** language from **MIT** (Massachusetts Institute of Technology). **Arduino** = open hardware ecosystem; **Arduino C** = text code on those boards. **IR** = infrared, used for remotes or line sensors.

## Before you buy (checklist)

1. **Brand and community** — Makeblock and ELEGOO have forums, GitHub and YouTube; avoid unknown “-50%” brands with no recent tutorials. See [Makeblock brand](/en/makeblock-brand/) and [ELEGOO brand](/en/elegoo-brand/).
2. **Useful sensors** — **Ultrasonic** distance, **line follower**, **RGB LEDs** and a **buzzer** keep projects interesting.
3. **Language path** — Blocks first, then **Arduino** or **Python** on the **same** chassis (mBot) extends life to the early teens.
4. **Total cost** — Rechargeable AA cells (**~£12–15**), optional line mat (**~£20–25**): budget **+£15–40** beyond the robot.

## Troubleshooting (mBot / mBlock)

| Symptom | Likely cause | Action |
| --- | --- | --- |
| No movement | Missing **when green flag clicked** hat | Add event block |
| Serial port missing | USB driver (CH340) | Reinstall mBlock; use USB |
| Bluetooth fails | Firmware / pairing | USB mode; [Bluetooth guide](/en/mblock-bluetooth-troubleshooting/) |
| Ultrasonic reads 0 | Wiring or too close | Check connector; test with hand |

For ELEGOO: select **Arduino UNO** in the IDE, pick the correct **COM** port, run **Blink** on the board alone before attaching the car chassis.
