Python reads almost like a sentence, and it shows up again in high school, in further study, and in a lot of software jobs. On a robot, a loop or a condition does not stay in the console: the motor turns, the LED lights, or the robot stops in front of the wall. It is the right language when a child has already seen blocks, or when they will write text with someone beside them.

Three machines cover the essentials, with prices from the Amazon.fr reading of 6 November 2026. The figures are euros, not converted dollar prices. The mBot2, at 167.95 euros, carries the CyberPi board and moves from blocks to Python without loose wiring. The CyberPi board alone, at 59.99 euros, suits someone who already has a chassis, or who only wants the screen, Wi-Fi, and sensors. The Raspberry Pi 5 8GB, at 209.09 euros, runs the Python of scientific libraries, at the cost of a power supply, a microSD card, and a case that are not in this reading. None of these three prices is a “project budget”: books, extra sensors, and a chassis for the Pi are checked separately. The buttons on this page open today’s listing.

## Why a robot rather than an exercise on a screen

Python’s syntax can be read aloud, and the libraries save you from rewriting everything. A child coming out of Scratch already knows variables, loops, and conditions. They lose drag-and-drop, and they gain text close to what people write later. That text is reused in high-school computer science, then in computing degrees, without the robot being required for what comes next.

On the day the program does not do what you planned, the documentation on docs.python.org and the forums answer most beginner errors. That is not a manufacturer hotline. For age, and for the move from Scratch to Arduino or Python, the landmark on this site is [when to start](/en/when-to-start-coding-with-kids/).

## Three ways to get Python on a robot

### A board already inside the robot

The mBot2 and the CyberPi run a simplified MicroPython. There is no system to install: mBlock sends the program in a few seconds, over USB or Wi-Fi. The editor shows the blocks and the text. You do not get the whole Python ecosystem of a computer, and that is exactly what makes the first sessions possible.

### Switching from blocks to text

mBlock, on the CyberPi, shows the block and the text that matches it. The child can go back to blocks on the day the text gets stuck. It is the least abrupt transition, as long as you accept the Makeblock environment rather than a Python you installed by hand.

## What you program, by age

Around 10–12, four ideas are enough for a year, without doing all of them in the same week. A line follower reads a sensor and corrects the two motors. Obstacle avoidance puts a condition on distance. A small onboard web page acts as a remote. A light show cycles through a list of colors. On mBot, sessions that are already written live in the [classroom projects](/en/10-free-mbot-classroom-projects/) and the [one-hour ideas](/en/mbot-one-hour-project-ideas/). Adapt them at home.

Around 13–15, you can display a measurement and send it further: temperature on the CyberPi screen, or a station on a Raspberry Pi with the [BME280 build](/en/smart-home/raspberry-pi-weather-station-bme280/). Face tracking needs a camera and OpenCV, so the Pi rather than the mBot2. A voice command or an autonomous maze stretches the same base, without changing machines.

From 16, the projects change in kind: mapping, object detection with a small model, several robots that talk to each other, or an arm whose path you calculate. The Pi 5 8GB is the board on this page with the memory for that. This guide does not describe how to build those projects. It only says which machine can carry them.

## Where you write the program

mBlock 5, at [mblock.cc](https://mblock.cc/), targets the mBot2 and the CyberPi. The interface shows the blocks and the text, the robot’s functions are already there, and you can send the program over Wi-Fi. It is the starting point until the child asks for a general-purpose editor.

Thonny comes preinstalled on Raspberry Pi OS, in the language of the system. It is enough for the first Python files, with a simple debugger, and it also talks to an ESP32 in MicroPython. The site thonny.org is there if you install it on the computer at home.

Visual Studio Code, at code.visualstudio.com, takes over when the project has several files, a Git repository, or a notebook. It is the tool for long projects, not the one for the first session on an mBot2.

Free courses that hold up are the Python path from France IOI, the introductory course on OpenClassrooms, and the documentation on docs.python.org (the French edition if you want it, the English edition as the source vocabulary). Real Python and Stack Overflow are in English, useful as soon as the question goes beyond the robot. French-language channels (Graven, Docstring, FormationVidéo) show the syntax on screen. Children’s books exist. No edition is in the price reading: there is no buy link here, so this page does not send you to a vague search.

Scratch stays the right start until about 10, then it blocks projects that do not fit in blocks. Python is the compromise that still reads clearly and that continues after the robot. Arduino in C is the path when the subject becomes the sensor, the motor, and the board, more than the language. You can perfectly well do Scratch for two or three months, then open the mBot2’s Python mode, without treating C as an obligation.

## Frequently asked questions

### Do you need Scratch before this?

No. It helps, because the loop and the condition are already there. A child who has never programmed gets through more easily with a few weeks of blocks, in mBlock, before the text. If they are already comfortable with a keyboard and they are 12 or older, Python mode can be the first contact, with an adult on the first syntax error.

### Which robot at 11?

The mBot2, at 167.95 euros on 6 November 2026, or the CyberPi alone at 59.99 euros if wheels are not the subject. Both keep the blocks within reach. A Raspberry Pi at that age is a good choice only if someone at home will install the system and wire it.

### Raspberry Pi or ESP32?

The Pi runs a full Python, a desktop, and a camera. The 8GB board in this reading is 209.09 euros, accessories on top. The ESP32 runs MicroPython, runs on a battery, and costs less as a board, but its price is not in this reading: check the listing for the exact module. It does not replace the Pi on the day the project opens a real vision library.

### What if the goal is artificial intelligence?

Take the Raspberry Pi 5 8GB board, at 209.09 euros on 6 November 2026, then a camera whose price you check separately. It is the only one of the three machines in this guide with the memory for a small detection model. The mBot2 remains the right robot for learning Python. It is not the platform for a vision project.

The choice fits in one sentence. To see a robot drive in Python without assembling a board, the mBot2 at 167.95 euros. For the same environment without the wheels, the CyberPi at 59.99 euros. For the libraries and the camera, the Pi 5 8GB at 209.09 euros, knowing that the board alone does not boot. All three amounts date from 6 November 2026 and may have moved on the listing.
