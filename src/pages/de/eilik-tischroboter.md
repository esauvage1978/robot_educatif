**Eilik** gehört zu den kleinen Tischbegleitern: er reagiert auf Berührung, zeigt Animationen auf einem kleinen Bildschirm und bietet kurze Spiele oder „Stimmungen“. Diese Seite sagt, wofür das gut ist. Es ist kein Robotik-Baukasten und kein Programmierkurs.

Diese Seite hat kein Produktfoto und keinen Ladenpreis. Der Preis steht auf der Anzeige des genauen Modells, an dem Tag, an dem Sie nachsehen.

## Wofür er taugt

| Ziel | Was so ein Begleiter oft leistet |
| --- | --- |
| Anfangen | Über Technik sprechen, bevor eine IDE aufgeht |
| Benennen | Eingaben (Berührung, eine Wahl), Ausgaben (Ton, Licht, Gesichter), eine Schleife von Reaktionen |
| Vergleichen | Eine Figur, die reagiert, gegen ein Projekt, dessen Logik man Schritt für Schritt schreibt |
| Takten | 15–20 Minuten, danach zum Beispiel der [scrollende Scratch-Boden](/de/scratch-spiel-hintergrund-verschieben/) oder [mBlock](/de/erste-schritte-mblock-5/) |

## Für wen

Etwa 8–14 Jahre, eine AG, ein Bibliothekstisch oder ein Familiengeschenk, das ein Gespräch über Sensoren öffnet. Eine Stunde kann einen längeren Kurs anfangen. Sie deckt allein kein Jahr „Robotik und Code“.

Vier kurze Stationen, ohne weiteres Material:

1. **Interview** (10 Minuten). Gruppen fragen „was macht er, wenn…?“ und notieren Eingabe, Reaktion, Regel.
2. **Zwei Spalten** (20 Minuten). Eine für Eilik, eine für einen anderen Gegenstand im Raum.
3. **Reaktion oder Anweisung.** „Er macht X, wenn ich Y tue.“ Was sofort spielbar ist, und was ein Programm woanders bräuchte.
4. **Ohne Bildschirm** für die Jüngeren. Die programmierbare Seite ist der Vergleich [mBot und Codey Rocky](/de/mbot-vs-codey-rocky/).

## Was er nicht ersetzt

Offenes Programmieren, einen Parcours, den die Schüler entwerfen, oder ein Halbjahr Sensoren. Ein Eilik kann die Vorführung auf dem Tisch sein. Der Rest der Gruppe braucht etwas, das jede Person wiederholen kann: [Scratch](/de/scratch-aktivitaet-quadrat/) oder [mBlock](/de/erste-schritte-mblock-5/).

## Fragen

**Braucht er einen Computer?** Oft nein, zum Spielen oder Vorzeigen. Ein Jahresprojekt mit Code braucht anderswo einen Rechner.

**Reicht er für den Code-Unterricht?** Nicht als einziges Werkzeug. Er kann der Grund sein anzufangen.

**Unterschied zu einem Schulroboter?** Eilik legt das Gewicht auf eine Figur und fertige Reaktionen. Ein Unterrichtsroboter legt es darauf, das Verhalten selbst zu schreiben. Beides kann im selben Jahr stehen. Es ist nicht dieselbe Aufgabe.
