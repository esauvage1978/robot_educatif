## Cosa cercare

Arduino, Raspberry Pi o una scheda con un vero percorso Python (il CyberPi dell'mBot2). Ricambi, tutorial, un linguaggio che esiste fuori dal giocattolo. Python, C/C++ su Arduino, JavaScript solo se il web interessa già.

La scatola è l'inizio. Sensori, un alimentatore serio e un corso sono acquisti separati. Quei prezzi si controllano il giorno dell'ordine.

## Decisione

Gli piacciono i circuiti: ELEGOO. Gli piace il computer e accetta che il robot arrivi dopo: Raspberry Pi 5. Vuole qualcosa che attraversi il tavolo questo weekend, poi Python: mBot2.

## Come capire che funziona

ELEGOO: uno sketch di esempio muove l'auto e lui cambia un valore di velocità. Pi: desktop avviato e un file Python modificato da lui che gira. mBot2: un programma a blocchi e un breve esempio Python muovono entrambi il robot. Se non succede nulla di questo, non comprate altri pezzi: sistemate la prima configurazione.
