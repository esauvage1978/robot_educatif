Il **[Raspberry Pi](/it/marchio-raspberry-pi/) 5** (fine 2023, SKU memoria ampliati 2024–2025) è un **SBC** (*single-board computer*: computer completo su una sola scheda). Si basa sul **BCM2712** con quattro core **Cortex-A76** a **2,4 GHz**, una GPU **VideoCore VII** e il controller **RP1** che gestisce **I/O** (ingressi/uscite: USB, Ethernet, ecc.) così il **SoC** (System-on-Chip — processore principale e periferiche su un unico chip) esegue i vostri programmi. I **GPIO** (General Purpose Input/Output — pin per sensori e moduli) restano compatibili con la maggior parte dei progetti Pi 3/4.

È anche la prima scheda «grande» Raspberry Pi di consumo con bus **PCIe** **2.0 ×1**, che permette un **SSD NVMe** (memoria flash veloce tramite scheda di espansione **HAT** certificata) oltre alla consueta **microSD**.

## 1. Le varianti RAM del Pi 5

| Variante | Uso tipico |
|----------|---------------|
| **1 GB** | **Edge** ultra-economico: script leggeri, gateway; poco margine per browser o **IDE** (ambiente di sviluppo integrato). |
| **2 GB** | Server minimalisti, display, bot; non ideale per desktop «famiglia» con molte schede. |
| **4 GB** | **Scelta di riferimento** 2026: desktop Raspberry Pi OS, sviluppo, stack web moderati, [Home Assistant](/it/domotica/installare-home-assistant-raspberry-pi-5/) confortevole. |
| **8 GB** | **Multi-container** (**Docker**: applicazioni isolate), database, compilazioni serie, desktop con molti servizi in background. |
| **16 GB** | Carico RAM raro su SBC: modelli IA locali leggeri, build grandi, **VM** (macchine virtuali) molto limitate; compratelo solo se sapete perché. |

Memoria **LPDDR4X-4267** sul Pi 5 (**LPDDR4-3200** sul Pi 4) — **RAM** saldata. Ancora tra Pi 4 e Pi 5? Vedi [Raspberry Pi 4: quale RAM](/it/raspberry-pi-4-quale-ram/).

## 2. Cosa cambia davvero rispetto al Pi 4

- **CPU**: nettamente più veloce in compilazione e encoding video.
- **PCIe / NVMe**: storage più rapido della sola microSD, con HAT compatibile e alimentazione adeguata.
- **Video**: pipeline **HDMI** modernizzata — aggiornate **Raspberry Pi OS**.
- **Termica**: il Pi 5 **scalda in fretta**; dissipatore attivo ufficiale quasi obbligatorio a lungo carico.
- **Alimentazione**: **5 V / 5 A** (27 W); caricatori deboli → **throttling** (rallentamento automatico per calore).

## 3. Quale versione scegliere? Albero decisionale rapido

1. **Budget stretto**, niente desktop: **2 GB** (o **1 GB** con RAM misurata).
2. **Primo acquisto** famiglia / scuola / maker: **4 GB** — se l’obiettivo è soprattutto robotica: [robot programmabili per bambini](/it/miglior-robot-programmabile-per-bambini/) e [robot 12 anni](/it/miglior-robot-educativo-2026/).
3. **Home lab** con **Docker** o più stack: **8 GB**.
4. **Progetti grandi**, modelli esigenti: **16 GB**, dopo aver verificato storage e raffreddamento.

Scarto prezzi: [confronto Pi 3 / 4 / 5](/it/raspberry-pi-3-vs-4-vs-5/) — tra **4 GB** e **16 GB** il prezzo può **raddoppiare o triplicare**.

## 4. Accessori da non dimenticare

- **Dissipazione attiva** (Active Cooler ufficiale o case equivalente).
- **Alimentatore** **5 V / 5 A** ufficiale o documentato.
- **microSD veloce**: classe **A2** (norma per alte velocità di lettura/scrittura per sistema e file temporanei) o **NVMe** con estensione PCIe — <a href="/go/az-it-169b8d5456/" rel="sponsored nofollow noopener">microSD A2 per Pi</a>.
- **Cavi micro-HDMI** per uno o due schermi.

## 6. Risoluzione problemi: RAM, alimentazione, lentezza

| Sintomo | Causa probabile | Cosa fare |
| --- | --- | --- |
| Sistema lentissimo, schede che si chiudono | **RAM** satura (spesso 2 o 4 GB con troppi servizi) | Chiudere app; al prossimo acquisto **8 GB** (RAM **saldata**); evitare swap permanente su microSD lenta |
| Icona termometro o CPU limitata | **Raffreddamento** insufficiente | Montare **Active Cooler** o case ventilato |
| Fulmine giallo | Alimentatore **&lt; 5 A** o cavo USB-C scadente | Alimentatore **5 V / 5 A** documentato per Pi 5 |
| Non avvia dopo aggiornamento | microSD usurata o corrotta | Reflash con **Imager**; provare **A2** nuova; **NVMe** se avete HAT |
| «Out of memory» con Docker/compilazione | Carico eccessivo per la variante | Meno container, compilare altrove, **8 GB** / **16 GB** |

Su Raspberry Pi OS: `free -h` nel terminale — colonna **available** = memoria libera.

## Domande frequenti

**4 GB o 8 GB per un primo Pi 5?**  
Nel 2026, **4 GB** coprono robotica, sensori, Home Assistant modesto e desktop ragionevole. **8 GB** per container, compilazioni pesanti o molti servizi.

**Ventola obbligatoria?**  
Per carichi oltre pochi minuti, di fatto sì — senza raffreddamento attivo il Pi 5 **rallenta**.

**Si può aumentare la RAM dopo?**  
No, memoria **saldata**. In dubbio: **4 GB** o **8 GB**.

**Cos’è lo «swap NVMe veloce»?**  
Lo **swap** è spazio disco usato come memoria di emergenza. Un **NVMe** rapido attenua il problema ma **non** sostituisce RAM sufficiente.
