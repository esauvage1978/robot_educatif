## Step 1: Prepare the microSD card or NVMe SSD

### Option A: Installation on microSD (recommended to start)

**Benefits** simple, NVMe migration possible later, no purchase if you already have an SD card.

**Steps**:

1. **Download Raspberry Pi Imager**: [rptl.io/imager](https://www.raspberrypi.com/software/) (Windows, Mac, Linux)
2. **Launch Imager**
3. **Select "Device"**: Raspberry Pi 5
4. **Select "Operating System"**:
   - Click "Other"
   - Go down to **"Home Assistant"**
   - Select (HAOS 13+ version in October 2026)
5. **Select "Storage"**: your microSD card (be careful not to go wrong with disk)
6. **Advanced Settings** (wheel notched lower right):
   - **Hostname**: `homeassistant` (recommended, facilitates `.local` access)
   - **SSH**: DO NOT ACTIVATE (HAOS handles SSH differently, via addon)
   - **WiFi**: configure only if no Ethernet available (SSID 2.4 GHz + password)
   - **Local** : `Europe/Paris`, keyboard `fr`
7. **Write**: danger confirmation  Yes  flashing (510 minutes)
8. **Remove SD card**, insert in Pi 5

**Duration**: 15 minutes (including 10 min flashing).

### Option B: NVMe Direct Boot (without microSD)

**Benefits** max speed, service life 10 years, 1 component less.

**Prerequisites** : firmware Pi 5 September 2024 (already installed on Pi 5 purchased after October 2024).

**Steps**:

1. **Connect NVMe SSD to PC**:
   - Either via HAT M.2 + USB adapter (if official HAT has USB mode)
   - Either via M.2  USB adapter (reusable)
2. **Raspberry Pi Imager** : same procedure as SD, but choose **SSD as storage** (appears as a USB drive)
3. **SSD Flasher** (10 min)
4. **Remove SSD from PC, attach to HAT M.2, screw on Pi 5**
5. **Start Pi 5** (without SD card)

**If boot error (LED flashes 4 times)**:
- Firmware Pi 5 obsolete update via temporary SD: [Official Raspberry Pi Doc](https://www.raspberrypi.com/documentation/computers/raspberry-pi.html#nvme-ssd-boot)

**Duration**: 20 minutes (flashing + HAT mounting).

## Step 3: Advanced network configuration (optional)

### Assign a fixed IP to the Raspberry Pi

**Why not?** Prevent IP change (DHCP), facilitates remote access and external automations.

**Method 1 DHCP Booking (Recommended)** :

1. **Internet Router Admin Interface**:
   - Freebox: Parameters  DHCP  Static leases
   - Livebox: Network  DHCP  Static leases
   - Bbox: Network Services  Static IP Attribution
2. **Find MAC address Pi 5**: interface box or `ip a` in SSH
3. **Reserve IP**: associate MAC with fixed IP (ex: `192.168.1.100`)
4. **Restart Pi 5** : `Paramètres → Système → Redémarrer`

**Method 2 HAOS configuration (advanced)**:

1. **SSH to HAOS** (activate addon Terminal & SSH first)
2. Edit `/etc/NetworkManager/system-connections/default`
3. Add Section `[ipv4]`:
   ```
   [ipv4]
   methodmanual
   address192.168.1.100/24
   gateway192.168.1.1
   dns192.168.1.1;8.8.8.8
   ```
4. Restart network: `nmcli connection reload`

**Check Fixed IP**: Restart Pi 5, check IP remains the same.

### Set up WiFi (if not Ethernet)

**Not recommended for primary use** (latency +20 ms, Zigbee interference 2.4 GHz).

**Configuration**:

1. **Parameters  System  Network**
2. **WiFi**: activate
3. **SSID**: select 2.4 GHz network (5 GHz not supported by built-in Pi 5 WiFi)
4. **Password**: enter WPA2 key
5. **Save** automatic connection

**Stability test** : `Outils développeur → ping homeassistant.local` from PC Latency < 10 ms = OK, > 50 ms problem.

   ```
## Step 7: Plug in the Zigbee dongle and configure ZHA

**ZHA** (Zigbee Home Automation): Zigbee native Home Assistant integration, supports 2000+ devices.

**Alternative**: Zigbee2MQTT (external addon, dedicated web interface, 2500+ devices). To start: **ZHA recommended**.

### Connecting the dongle

1. **ZBDongle - E** on the USB port of the Pi 5 (USB 2.0 or 3.0, whatever)
2. **Wait for 10 seconds** (automatic detection)
3. **Check detection** : `Paramètres → Système → Matériel → Tout le matériel` Search `/dev/ttyUSB0` or `/dev/ttyACM0`

**If absent**: test other USB port, change cable, restart Pi 5.

### Configure ZHA

1. **Settings  Devices and Services  Add Integration**
2. Search **"ZHA"** (Zigbee Home Automation)
3. **Select serial port**: `/dev/ttyUSB0` (or `/dev/ttyACM0`)
4. **Type of radio** EZSP (EmberZNet Serial Protocol) automatic detection for ZBDongle-E
5. **Speed**: 115200 baud (default)
6. **Flow control**: hardware (default)
7. **Submit** ZHA initializes coordinator (30 seconds)

**ZHA screen**: "Zigbee Home Automation configured"  coordinator created.

### Pairing a first Zigbee sensor

**Example**: SONOFF SNZB-02D (temperature + humidity sensor).

   - Hold button for 5 seconds
   - LED flashes quickly (red/blue alternating)
4. **Appearance HA** : 1030 seconds "SONOFF SNZB-02D"
5. **Rename**: "Living room sensor"  Zone: Living room

**Entities created**:
- `sensor.capteur_salon_temperature` (°C)
   ```

     ```
## Troubleshooting: 5 Common Problems

### Problem 1: Pi 5 does not start (green LED flashes 4 times)

**Symptoms**:
- LED red (power supply) fixed
- Green LED flashes 4 times in a loop
- No display screen (if HDMI plugged in)

**Causes**:
- **NVMe Boot Fails** : firmware Pi 5 obsolete ( sept 2024)
- **Corrupted SD card**: Incomplete flashing or defective card
- **Insufficient nutrition** 15W instead of 27W

**Solutions**:
1. **Remove NVMe**, insert SD card (boot SD still works)  if boot: update firmware via `sudo rpi-eeprom-update -a`
2. **Reflasher SD Card** with Raspberry Pi Imager (new card if possible)
3. **Test food** : measure USB-C voltage (must be 5V 0.25V). If 4,5V: defective power supply.
4. **Check HAT NVMe** well pressed (40-pin header complete)

### Problem 2: `homeassistant.local` is not working

**Symptoms**:
- Browser: "Site not found" or "DNS_PROBE_FINISHED_NXDOMAIN"
- Ping `homeassistant.local` fails

**Causes**:
- **mDNS Blocked** by router (Freebox, Bouygues Bbox)
- **Windows without Hello** (Apple service for mDNS)
- **Firewall blocks port 5353** (mDNS)

**Solutions**:
1. **Find IP manually**: interface box  list of devices  note IP
2. **Navigate to IP**: `http://192.168.1.42:8123`
3. **Install Hello** (Windows): [support.apple.com/kb/DL999](https://support.apple.com/kb/DL999) or iTunes
4. **Disable firewall** Temporarily to test
5. **Using Fing** (mobile app): network scanner find IP Pi 5

### Problem 3: Random Freeze, Untimely Restarts

**Symptoms**:
- HA randomly inaccessible (12 per week)
- Dashboard no longer loads
- Logs: kernel panic, undervoltage warning

**Causes**:
- **Undernutrition** (cause 1): unofficial 15W power supply
- **Corrupted SD card**: HA-intensive writes (10 GB/day)
- **Overheating CPU** > 80 °C without fan
- **Defective USB-C cable**

**Solutions**:
1. **Replace with official 27W power supply** ([Amazon Link](https://www.amazon.co.uk/s?k=raspberry+pi+power+supply+27w&tag=roboteducatif-21))
2. **Check Temperature** : `Paramètres → Système → Informations → Température` (must be 70 °C idle)
   - If > 75 °C: add active fan or passive aluminium housing
3. **Migrating to NVMe** : Replace corrupted SD with SSD (lifetime 10 years)
4. **Check logs** : `Paramètres → Système → Journaux` look for "undervoltage" ( insufficient power supply)

### Problem 4: Zigbee dongle not detected

**Symptoms**:
- `/dev/ttyUSB0` missing in Hardware
- ZHA refuses to install ("No radio found")

**Causes**:
- **Unpowered USB Hub** (if dongle plugged into external hub)
- **Defective USB-A USB-C cable** (some are charge-only)
- **Failed USB port** (rare)
- **Defective dongle** (5% of ZBDongle-E cheap)

**Solutions**:
1. **Connect directly** on Pi 5 (no intermediate hub)
2. **Test other USB port**: Pi 5 has 4 ports, try all
3. **Check for Linux detection** Terminal SSH `ls /dev/tty*` must display `ttyUSB0` or `ttyACM0`
4. **Test dongle on Windows PC**: Simplicity Studio (Silabs) must detect EFR32MG21

### Problem 5: SD card corrupted after 612 months

**Symptoms**:
- HA no longer starts (boot blocked)
- Logs: "Read-only file system" or "I/O error"
- Unable to save (write error)

**Causes**:
- **Low-end SD card**: 10,000 write cycles vs. 100,000 (SanDisk Extreme)
- **HA Intensive Writings** : 1020 GB/day (database, logs)
- **No maintenance**: history never purged (database 50 GB)

**Solutions**:
1. **Preventive** : to buy **SanDisk Extreme** or **Samsung EVO Plus** (A little more expensive, but more durable)
2. **Migrate NVMe**: SSD  10 years lifetime, 0% corruption
3. **Reduce Writings** : `configuration.yaml` Limiting history:
   yaml
   Recorder:
     purge_keep_days: 7  Instead of 10 by default
     Excludes:
       Domains:
         - Updater
         - Automation
   ```
4. **Restore from backup**: new SD flasher, restore last backup
