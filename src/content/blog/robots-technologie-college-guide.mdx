Les cours de **technologie au collège** (cycles 3 et 4) intègrent désormais la **programmation** et la **robotique** dans les programmes officiels 2020. Ce guide vous aide à **choisir les bons robots**, comprendre les **attendus pédagogiques** par niveau, et préparer des **séquences** conformes aux **repères de progression**.

## 1. Programmes officiels 2020 : ce qui est attendu

### Cycle 3 (6e)

**Compétences** :
- Programmer les déplacements d'un robot
- Utiliser des capteurs simples (distance, ligne)
- Comprendre la notion d'algorithme (séquence, boucle)
- Tester et valider un programme

**Langages** : Scratch ou équivalent (blocs)

**Volume horaire** : 6-8 séances robotique/an (sur 36 séances techno)

### Cycle 4 (5e-4e-3e)

**Compétences** :
- **5e** : Conditions, variables, capteurs multiples
- **4e** : Algorithmique structurée, introduction Python (recommandé BO)
- **3e** : Projets longs, interaction capteurs/actionneurs, IoT

**Langages** : Scratch (5e) → Python (4e-3e)

**Volume horaire** : 8-12 séances/an (dont projet final 3e)

## 3. Progression pédagogique 4 ans

### 6e : Découverte blocs (8 séances)

1. **Montage robot** (1h) : vis, moteurs, câbles
2. **Premiers déplacements** (1h) : avancer, tourner, stop
3. **Capteur ultrason** (2h) : distance, seuil, alerte
4. **Suiveur de ligne** (2h) : capteurs, boucle, régulation
5. **Projet libre** (2h) : défis imposés binômes

**Évaluation** : grille observation + autoévaluation

### 5e : Algorithmique structurée (10 séances)

1. **Révision blocs** (1h) : retrouver réflexes 6e
2. **Variables** (2h) : compteur, score, timer
3. **Conditions imbriquées** (2h) : ET/OU, priorités
4. **Sous-programmes** (2h) : fonctions réutilisables
5. **Projet labyrinthe** (3h) : autonomie complète

**Évaluation** : projet noté (programme + démo)

### 4e : Transition Python (10 séances)

1. **Découverte Python** (2h) : syntaxe, indentation
2. **Mêmes défis en Python** (3h) : traduction Scratch
3. **Nouveaux capteurs** (2h) : température, lumière
4. **Affichage graphique** (1h) : CyberPi écran
5. **Mini-projet IoT** (2h) : notification téléphone

**Évaluation** : QCM Python + programme commenté

### 3e : Projet long (12 séances)

1. **Cahier des charges** (1h) : besoins, contraintes
2. **Conception** (2h) : algorithme, logigramme
3. **Réalisation** (6h) : code, tests, debug
4. **Documentation** (1h) : notice utilisateur
5. **Soutenance** (2h) : démo + oral 5 min

**Évaluation** : oral DNB Blanc (compétences transversales)

## 4. Activités clés en main par niveau

### 6e : Feu tricolore

**Objectif** : Alterner LED rouge/vert avec temporisations

**Blocs Scratch** :
```
Quand drapeau cliqué
Répéter indéfiniment
  Allumer LED rouge
  Attendre 3 secondes
  Éteindre LED rouge
  Allumer LED verte
  Attendre 2 secondes
  Éteindre LED verte
```

**Compétences** : Séquence, boucle, temporisation

**Durée** : 1h (30 min code + 30 min tests)

### 5e : Radar de recul

**Objectif** : Son et LED selon distance obstacle

**Algorithme** :
- Distance > 50 cm : LED verte, pas de son
- 20-50 cm : LED orange, bip lent
- < 20 cm : LED rouge, bip rapide

**Compétences** : Conditions multiples, variables

**Durée** : 2h (inclus découverte capteur ultrason)

### 4e : Station météo (Python)

**Objectif** : Afficher température + humidité sur écran CyberPi

**Python mBot2** :
```python
import cyberpi
import time

while True:
    temp = cyberpi.get_temperature()
    cyberpi.display.show_label(str(temp) + "°C", 16)
    time.sleep(1)
```

**Compétences** : Bibliothèques, boucle infinie, affichage

**Durée** : 2h (découverte syntaxe Python)

### 3e : Parking intelligent

**Objectif** : Compter entrées/sorties, afficher places libres

**Capteurs** : 2× ultrason (entrée/sortie)

**Variables** : `places_totales`, `places_occupees`

**Affichage** : Écran couleur + LED verte/rouge

**Compétences** : Architecture complexe, états, IHM

**Durée** : 6h (projet complet)

## 5. Gestion classe et îlots

### Organisation type (24 élèves, 8 robots)

- **Îlots de 3** élèves
- **Rôles tournants** :
  - Pilote : tape le code
  - Copilote : dicte/vérifie
  - Testeur : manipule robot

**Rotation** : tous les 15 min

### Éviter les conflits

- ✅ Chaque binôme = 1 couleur (autocollant robot)
- ✅ Fiche suivi (qui a fait quoi)
- ✅ Temps imposés (chrono visible)
- ❌ "Premier arrivé, premier servi" (chaos)

### Rangement

- Checklist plastifiée : câble, télécommande, vis
- Responsable matériel (2 élèves/semaine)
- Sanction douce : 5 min nettoyage si oubli
