Équiper une classe en **robots éducatifs** nécessite de jongler entre **budget**, **pédagogie**, **maintenance** et **évolutivité**. Ce guide vous aide à choisir le bon nombre de robots, le bon modèle, et à anticiper tous les coûts cachés (piles, rangement, licences, formation).

## 1. Combien de robots pour combien d'élèves ?

### Scénario primaire (CE2-CM2) : 24-28 élèves

- **Option A** : 6 robots pour travail en **groupe de 4**
  - Budget : ~600-900€
  - Avantage : collaboration, coût maîtrisé
  - Inconvénient : temps d'attente, gestion tour de rôle

- **Option B** : 12 robots pour travail en **binôme**
  - Budget : ~1200-2000€
  - Avantage : tous actifs, moins de conflits
  - Inconvénient : rangement, charge mentale enseignant

**Notre recommandation primaire** : 8 robots = 3-4 élèves/robot (sweet spot budget/péda).

### Scénario collège (6e-3e) : 24-30 élèves

- **Technologie** : 8-10 robots suffit (îlots 3 élèves)
- **Club robotique** : 4-6 robots (effectif 12-15)
- **Classe NSI lycée** : 12-15 robots (binômes, projets longs)

### Primaire (CE2-CM2) + 6e-5e

➜ **mBot classique** 

**Pourquoi** :
- Scratch natif (programme 2020)
- Montage 15 min (séance découverte possible)
- Réparations simples (vis apparentes)
- Documentation française abondante

**Budget 8 robots** : 720€ (kits) + 150€ (piles rechargeables × 3 lots) + 100€ (rangement) = **~970€**

### Collège 4e-3e + NSI lycée

➜ **mBot2**  **OU** mBot classique + modules Python

**Pourquoi mBot2** :
- Python cycle 4 (BO 2020)
- CyberPi = progression naturelle Scratch → Python
- Projets IoT (météo, notifications, dashboard web)
- Compatible mBuild (capteurs avancés)

**Budget 6 mBot2** : 1008€ (kits) + 120€ (accessoires) + 150€ (rangement modulaire) = **~1278€**

**Alternative économique** : 8 mBot + 2 mBot2 (démonstration prof) = **~1056€**

### Lycée NSI / STI2D

➜ **ELEGOO Robot Car V4.0**  ou **Raspberry Pi 4/5** + châssis

**Pourquoi** :
- Arduino C/C++ (proche industrie)
- Caméra FPV, capteurs multiples
- Projets finaux BAC (vision, IA)
- Communauté maker immense

## 4. Financement et aides

### Appels à projets 2026

- **Région** : "Équipement numérique" (500-5000€)
- **CARDIE** : Projets innovants (1000-3000€)
- **Fondations entreprises** : Total, Orange, CGenial (variable)
- **Mairies** : Budget fournitures + équipement

**Calendrier** : septembre-novembre dépôt, janvier-mars attribution.

### Coopérative scolaire / FSE

- Bénéfices photos de classe
- Tombola / vente gâteaux
- Sponsors parents (listing donateurs fléchés)

### Prêt matériel DANE / Canopé

Certaines académies prêtent **kits robotiques** 4-8 semaines (réserver 3 mois avant).

## 5. Coûts cachés et maintenance

### Première année

- **Formation enseignant** : 3-6h (PAF gratuit OU 300€ privé)
- **Temps installation** : 2-4h (firmware, Bluetooth, tests)
- **Assurance casse** : incluse mobilier scolaire habituellement

### Années suivantes (annuel)

- **Piles** : 30-50€/an (mBot classique)
- **Pièces détachées** : 50-100€/an (roues, vis, capteurs)
- **Renouvellement** : 1 robot sur 8 tous les 2 ans (~100€/an)

**Total maintenance** : 150-250€/an pour classe 8 robots.

### Obsolescence

- **mBot classique** : 5-7 ans (firmware maintenu jusqu'en 2030 minimum)
- **mBot2** : 5-8 ans (plateforme récente, maj logicielles)
- **ELEGOO** : 4-6 ans (compatibilité Arduino éternelle)

## 6. Rangement et logistique

### Solutions économiques

- **Bacs IKEA Samla 22L** : 5-8€ pièce, 2 robots/bac
- **Étagères métal** : 50-100€ (charge 50kg)
- **Étiquettes couleur** : binôme = couleur (rouge, bleu…)

### Solutions pro

- **Valises Peli** : 100-200€ pièce (transport sûr, mousse découpée)
- **Chariots classe mobile** : 400-800€ (charge 16 robots + tablettes)

### Signalétique

- Numéroter chaque robot (autocollant)
- Fiche inventaire plastifiée
- Checklist retour fin séance (vis, câbles, télécommande)

## 7. Licences logicielles

### mBlock (mBot/mBot2)

- **Version web** : gratuite, illimitée
- **Version bureau** : gratuite, illimitée
- **Pas de licence** enseignant nécessaire

### Arduino IDE (ELEGOO)

- **100% gratuit** et open source
- Pas de restriction établissement

### Conclusion logiciels

➜ Aucun coût licence récurrent pour robots éducatifs standards.

## 9. Commande groupée : conseils

### Revendeurs agréés Éducation

- **Génération Robots** : remise 10-15% sur devis
- **Technologie Services** : paiement mandat administratif
- **Amazon Business** : facture établissement, retours simplifiés

### Documents à préparer

1. Devis détaillé (références exactes ASIN/SKU)
2. Bon de commande signé chef établissement
3. RIB établissement (virement)
4. Délai livraison (prévoir 2-4 semaines)

### Éviter les pièges

- ❌ Clones low-cost sans SAV (économie 20% = casse 80%)
- ❌ Kits "éducation" gonflés (+30% pour mallette inutile)
- ❌ Achats fractionnés (perdre remises quantité)
