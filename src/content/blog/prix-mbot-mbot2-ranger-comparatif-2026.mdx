### Différence clé : CyberPi

Le **CyberPi** est une carte programmable complète :
- Écran couleur LCD
- Microphone + haut-parleur
- Accéléromètre 6 axes
- Capteur de lumière
- Wi-Fi 2.4GHz
- Batterie lithium rechargeable

Cette carte transforme le mBot2 en **vrai ordinateur mobile** capable de projets IoT (météo connectée, notifications Telegram, dashboard web).

### Pour qui ?

- **Collège/lycée** : transition naturelle Scratch → Python
- **Enfant 10+ ans** passionné tech : IoT, capteurs avancés, projets longs
- **Clubs robotique** : compétitions type First Lego League nécessitant code structuré

### Surcoût justifié ?

**Oui** si :
- Objectif Python clair (collège, NSI, orientation ingénieur)
- Budget classe permet 3-5 robots mBot2 plutôt que 8 mBot classiques
- Projet annuel prévu (station météo, robot messager…)

**Non** si :
- Première découverte sans engagement
- Budget très serré
- Enfant préfère construction mécanique au code

## 8. Questions fréquentes

### Le mBot2 peut-il tout faire comme le Ranger ?

**Non** : le Ranger a un châssis spécifique et gyroscope pour l'équilibrage. Le mBot2 ne peut pas se transformer en robot auto-équilibré sans acheter kit Ranger séparément.

### Puis-je upgrader mon mBot classique en mBot2 ?

**Partiellement** : acheter CyberPi séparé (~60€) permet de remplacer mCore et gagner Python + Wi-Fi. Mais il manquera écran couleur optimisé et certaines fonctions mBot2 natives.

### Faut-il acheter les trois ?

**Non**, sauf club robotique ou collection. Choisir **un** modèle adapté à l'âge/objectif, puis éventuellement **un second** après 6-12 mois si vraiment passionné.

### Les prix vont-ils baisser ?

Historiquement, Makeblock maintient prix stables. Promotions possibles :
- **Black Friday** (novembre)
- **Rentrée scolaire** (août-septembre)

Économies attendues : 5-15% maximum.
