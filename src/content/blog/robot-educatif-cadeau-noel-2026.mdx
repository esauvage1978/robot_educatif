## Pourquoi offrir un robot à Noël ?

### 1. Cadeau qui dure

Contrairement aux jouets classiques :
- **Pas de pile à changer tous les 3 jours** (batteries rechargeables)
- **Évolution** : le robot grandit avec l'enfant (Scratch → Python)
- **Projets infinis** : on ne s'ennuie jamais

### 2. Éducatif sans en avoir l'air

L'enfant apprend sans s'en rendre compte :
- **Logique** et résolution de problèmes
- **Programmation** (compétence clé du 21e siècle)
- **Électronique** et mécanique
- **Patience** et persévérance

### 3. Activité parent-enfant

Les vacances de Noël sont parfaites pour :
- **Déballer et assembler** le robot ensemble
- **Faire les premiers programmes** en famille
- **Créer des parcours** au sol
- **Filmer** les réussites pour les partager

### 4. Alternative aux écrans passifs

Au lieu de 4h de YouTube/TikTok :
- **Écran actif** : l'enfant crée, ne consomme pas
- **Manipulation physique** : le robot bouge dans le réel
- **Déconnexion possible** : certains robots fonctionnent sans écran

## Accessoires pour augmenter le panier (et le plaisir)

Ne vous arrêtez pas au robot seul ! Ces **compléments malins** augmentent la **valeur perçue** et la **durée de jeu** :

### Essentiels (à commander en même temps)

**Piles rechargeables** : Le robot va tourner H24 en vacances
- **AA (4-8 piles)** : pour mBot, mBot2 (15-20€)
- **AAA (4 piles)** : pour certains robots bipèdes (12-15€)
- **Chargeur USB** : pratique pour toute la famille (25-30€)

**[Voir les piles rechargeables sur Amazon](https://www.amazon.fr/s?k=piles+rechargeables+AA&tag=manuso06-21)**

### Extensions et kits complémentaires

**Tapis de parcours** : Transforme le salon en circuit de compétition
- **Tapis ligne noire** : pour suiveur de ligne (20-30€)
- **Circuit imprimé** : défis progressifs (25-40€)

**[Voir tapis de parcours robot sur Amazon](https://www.amazon.fr/s?k=tapis+parcours+robot&tag=manuso06-21)**

**Kits d'extension Makeblock** : Pour mBot/mBot2 qui durent 3-5 ans
- **Servo Pack** : ajouter bras/pince (30-40€)
- **LED Matrix** : affichages personnalisés (25-35€)
- **Capteurs supplémentaires** : son, couleur, IR (20-50€)

**[Voir extensions mBot sur Amazon](https://www.amazon.fr/dp/B07XR98YYQ?tag=manuso06-21)**

## Conseils pour réussir le cadeau

### 1. Vérifier les prérequis

- **Ordinateur / tablette** : nécessaire pour Scratch/Python
- **Wi-Fi** : certains robots en ont besoin
- **Temps adulte** : première session ensemble (1-2h)

### 2. Calculer le budget total

Budget réaliste = **Robot + accessoires + marge imprévus**

Exemple mBot 8 ans :
- mBot : 90€
- Piles rechargeables : 18€
- Livre Scratch : 20€
- Tapis ligne : 25€
- **Total** : **153€** (au lieu de 90€ seul)

### 3. Offrir en avance ?

Si vous offrez le 25 décembre :
- **Prévoir 1-2h** pour l'assemblage
- **Charger les batteries** la veille
- **Installer le logiciel** sur PC/tablette avant

**Astuce** : offrez le 24 au soir pour assembler ensemble le 25 matin.

### 4. Emballer malin

Les boîtes de robots sont souvent **grandes et carrées** :
- **Papier kraft** + ficelle + dessin robot dessus
- **Sac cadeau XXL** réutilisable
- **Carton mystère** avec indices programmation
