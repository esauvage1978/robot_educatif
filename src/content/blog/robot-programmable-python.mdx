**Python** est devenu **le** langage de programmation le plus enseigné au monde : IA, data science, web, automatisation. Apprendre Python avec un **robot** rend l'apprentissage **concret** : au lieu de simples exercices console, l'enfant voit son code **bouger**, **allumer des LEDs**, **éviter des obstacles**.

## Pourquoi Python pour la robotique ?

### 1. Langage professionnel accessible

Python combine :
- **Syntaxe claire** : proche de l'anglais, facile à lire
- **Puissance** : utilisé par Google, NASA, Instagram
- **Bibliothèques** : des milliers de modules pour tout faire

### 2. Transition naturelle depuis Scratch

Pour un enfant qui a fait du Scratch :
- Les **concepts** sont les mêmes : variables, boucles, conditions
- Mais on passe au **texte** : plus de liberté, plus proche du code réel

### 3. Compétence durable

Python appris à 12 ans servira :
- Au **lycée** (spécialité NSI)
- En **études supérieures** (école d'ingé, fac info)
- En **carrière** (dev, data, IA)

### 4. Communauté immense

Quand l'enfant bloque :
- Stack Overflow a **des millions** de réponses
- Tutoriels YouTube par milliers
- Forums spécialisés robotique Python

## À quel âge débuter Python avec un robot ?

| Âge | Niveau | Robot adapté |
|-----|--------|--------------|
| 8-10 ans | Fin de Scratch, accompagnement fort | CyberPi, mBot2 avec mBlock Python |
| 11-13 ans | Autonomie moyenne, motivation | mBot2, Raspberry Pi avec kit robot |
| 14+ ans | Projets longs, IA/vision | Raspberry Pi 5, ESP32 + MicroPython |

**Important** : Python **pur** (IDLE, VSCode) est plus difficile que **MicroPython** dans un environnement graphique (mBlock). Commencez par ce dernier.

## Types de robots Python

**Principe** : carte embarquée (ESP32, RP2040) avec environnement simplifié.

**Avantages** :
- **Démarrage rapide** : pas d'OS à installer
- **Interface graphique** : éditeur intégré (ex : mBlock 5)
- **Retour immédiat** : upload du code en quelques secondes

**Exemples** : mBot2 (CyberPi), CyberPi seul

## Projets Python concrets avec un robot

### Débutant (10-12 ans)

1. **Robot suiveur de ligne** : lire capteur, ajuster moteurs
2. **Évitement d'obstacles** : boucle, condition, capteur ultrason
3. **Télécommande Wi-Fi** : serveur web simple sur le robot
4. **Jeu de lumières** : boucles, listes, LEDs RGB

### Intermédiaire (13-15 ans)

1. **Station météo connectée** : capteurs + affichage + API
2. **Suivi de visage** : OpenCV (sur Raspberry Pi)
3. **Robot vocal** : reconnaissance vocale + actions
4. **Labyrinthe autonome** : algorithme de résolution

### Avancé (16+ ans)

1. **SLAM** : cartographie simultanée (lidar + algorithmes)
2. **IA embarquée** : TensorFlow Lite pour détection d'objets
3. **Swarm robotics** : plusieurs robots coordonnés
4. **Bras robotique** : cinématique inverse, trajectoires

## Python vs Scratch vs Arduino C

| Critère | Python | Scratch | Arduino C |
|---------|--------|---------|-----------|
| Lisibilité | ★★★ | ★★★ | ★★ |
| Puissance | ★★★ | ★ | ★★ |
| Courbe apprentissage | ★★ | ★★★ | ★ |
| IA/Data | ★★★ | ★ | ★ |
| Embarqué | ★★ | ★ | ★★★ |
| Carrière | ★★★ | ★ | ★★ |

**Résumé** :
- **Scratch** : parfait jusqu'à 10 ans, mais limitant après
- **Python** : le meilleur équilibre accessibilité/puissance/carrière
- **Arduino C** : indispensable pour l'électronique bas niveau

## FAQ

**Faut-il connaître Scratch avant Python ?**  
Non, mais ça aide. Si l'enfant n'a jamais programmé, commencez par 2-3 mois de Scratch.

**Quel robot Python pour débuter à 11 ans ?**  
mBot2 ou CyberPi. Interface graphique + Python embarqué = combo idéal.

**Python sur Raspberry Pi vs sur ESP32 ?**  
Raspberry : Python complet, IA, projets lourds. ESP32 : MicroPython, embarqué léger, économe.

**Mon enfant veut faire de l'IA, quel robot ?**  
Raspberry Pi 5 (8GB) pour faire tourner TensorFlow Lite et OpenCV.
