## Que peut-on poser sans l'accord du propriétaire ?

En France, la [loi du 6 juillet 1989](https://www.legifrance.gouv.fr/loda/id/JORFTEXT000000509310), article 7, fixe deux obligations qui comptent ici. Le locataire use paisiblement des locaux. Il ne transforme pas les locaux ni les équipements loués sans l’accord écrit du propriétaire. Le [service-public.fr](https://www.service-public.gouv.fr/particuliers/vosdroits/F1874) le résume ainsi : aménager librement, oui ; gros travaux de transformation, non, sauf accord écrit. Un bail peut être plus strict que ce plancher. Lisez la clause « travaux » et la clause sur le bruit avant d’acheter.

Un robot posé au sol, un câble USB et une multiprise qui vous appartient ne transforment pas le logement. Un rail vissé dans le mur, un trou dans le plan de travail fourni avec la location, ou un module derrière un interrupteur, si. Pour l’électricité du bâtiment, le guide domotique renvoie vers un électricien et un accord écrit. Ici, tout reste branché sur une prise existante.

L’usage paisible vise aussi le voisinage. Les moteurs d’un petit robot s’entendent dans la pièce. Un mur mitoyen peut transmettre le roulement en soirée. La vérification utile se fait sur place. Faites tourner le robot dix minutes en fin d’après-midi, porte fermée, et demandez à quelqu’un dans la pièce d’à côté s’il l’entend.

## Comment trancher entre les familles ?

Quatre questions suffisent, dans cet ordre.

**Qui programme ?** Un enfant qui débute a besoin d’un résultat dans l’heure : le robot roule, une lumière change. Un ado ou un adulte qui veut comprendre un fil accepte une soirée de montage. Le [kit pour adulte débutant](/kit-robotique-adulte-debutant/) détaille Arduino, ESP32 et Raspberry Pi une fois cette question tranchée.

**Combien de sol est vraiment libre ?** Moins d’un mètre : Codey Rocky, Penguin Bot ou une carte. Un mètre dégagé que vous pouvez rendre le soir : mBot, mBot2 ou voiture ELEGOO. Un couloir partagé en colocation ne compte pas. Le robot reste dans votre pièce, pas dans le passage.

**Combien de temps restez-vous ?** Sous six mois, le prix d’entrée compte plus que les capteurs. Le Penguin Bot était à 39,99 €. Au-delà d’un an, le mBot2 ou une carte que vous réutiliserez valent le supplément, parce que vous les emportez.

**De quel réseau disposez-vous ?** Le mBot classique communique en USB, Bluetooth et 2,4 GHz, sans Wi-Fi sur la [fiche Makeblock](https://www.makeblock.com/products/buy-mbot). Dans une résidence où la box n’est pas la vôtre, ou derrière un portail captif, le câble USB est le chemin fiable. Le mBot2 ajoute une option Wi-Fi 2,4 GHz. Vous pouvez vous en passer pour les premiers programmes. Si un projet a besoin du réseau, un partage de connexion depuis votre téléphone évite d’ouvrir un port sur la box du propriétaire.

Le détail mBot contre Codey Rocky est dans le [comparatif des deux châssis](/mbot-vs-codey-rocky-comparatif/). mBot contre mBot2 est dans l’[autre comparatif](/mbot-vs-mbot2-comparaison-des-robots-educatifs-pour-enfants/).

## Comment installer le coin en une soirée ?

1. Relisez le bail. Repérez la clause travaux et ce qui est dit du bruit. Si une heure limite est écrite, les moteurs tournent avant.
2. Protégez la table du logement avec un sous-main qui vous appartient. Aucune vis dans le plateau.
3. Si le robot roule, dégagez environ un mètre sur un mètre. Ramassez le tapis ou le câble de lampe qui traîne.
4. Préparez une boîte à couvercle et un sachet pour les vis. Écrivez le nom du kit sur la boîte le premier soir.
5. Branchez votre multiprise à interrupteur sur une prise déjà là. Coupez-la quand vous partez plusieurs jours.
6. Suivez la notice du fabricant pour le montage. Makeblock annonce environ 15 minutes pour le mBot. Les fiches de la configuration standard du Codey Rocky décrivent une pose du boîtier sur le châssis, pas un châssis à visser.
7. Reliez le robot en USB. Pour un Makeblock, installez mBlock avec le [guide Windows](/installer-mblock-5-sous-windows-10/), puis le [premier pas dans le logiciel](/premier-pas-avec-mblock-5/). Le [premier programme mBot](/mon-premier-programme-mbot/) fait avancer le robot. Pour ELEGOO, l’IDE Arduino et les exemples du fabricant, aussi téléchargeables depuis la page officielle, servent de point de départ. Suivez les intitulés imprimés dans la notice du carton.
8. Observez le mouvement. Le robot part, puis s’arrête parce que le programme le dit, ou parce que l’ultrason voit un obstacle si ce capteur est dans le programme. Un mBot2 lancé à la vitesse maximale de la fiche met environ cinq secondes pour un mètre.
9. Rangez. Dix minutes, boîte fermée, table nue, aucun adhésif sur la peinture. Si le rangement déborde sur une seconde boîte oubliable, le kit est trop dispersé pour un déménagement.

Le lendemain, le même programme doit refaire le même trajet. C’est le contrôle que le câble, la batterie et les vis sont encore ensemble.

## Comment tout emporter le jour du déménagement ?

Sortez les piles AA. Pour une batterie lithium, suivez la notice du fabricant. Si un transporteur prend les cartons, les batteries au lithium ont leurs propres règles d’envoi : gardez le robot avec vous, ou lisez les conditions du transporteur avant de le confier.

Retirez le robot du Wi-Fi du logement si vous l’y aviez inscrit. Le mBot classique n’a pas cette étape. Le mBot2 peut l’avoir. Emportez le câble USB, la microSD si vous avez un Pi, la notice et le sachet de vis dans la même boîte. Photographiez le coin vide. Vous pourrez le comparer aux photos de l’état des lieux d’entrée. Rien ne doit rester branché, et aucun trou nouveau ne doit apparaître sur le mur ou sur la table.

## Que laisse-t-on de côté ?

Une imprimante à résine et un graveur laser demandent une ventilation, et le laser ajoute un risque pour les yeux et un risque de feu. Un logement loué, souvent une pièce unique, ne s’y prête pas. Leur mise en route se décide dans un local ventilé.

Une imprimante FDM posée sur la table occupe la place pendant des heures, fait du bruit, et certains filaments sentent. Elle peut repartir avec vous, mais ce n’est pas le premier achat pour apprendre à programmer un robot.

Un grand set de briques de classe, du type SPIKE, se range mal dans un studio à cause du nombre de pièces. Le point de comparaison est dans [les alternatives à SPIKE Prime](/lego-education-computer-science-ai-2026-alternatives-spike-prime/).

Un aspirateur robot relève d’un autre choix, sol et station de charge compris. Le guide est [l’aspirateur à moins de 200 €](/domotique/robot-aspirateur-moins-de-200-euros/).

Le fer à souder sur la table du logement attend un sous-main et une fenêtre ouverte. Les kits à connecteurs et les robots déjà montés évitent cette étape pour le premier mois.

## Quand ça coince

**Le robot ne roule pas le jour de l’ouverture.** Sur un mBot, les piles ne sont pas dans la boîte. Achetez-les avant la séance, ou la batterie optionnelle, et respectez le 5 V / 1 A si vous chargez par l’USB. Sur un Codey Rocky ou un mBot2, chargez avant de juger le moteur.

**Le voisin entend les roues.** Déplacez la séance plus tôt. Posez le robot sur un tapis qui vous appartient, pour limiter le contact direct avec le parquet du logement. Si on l’entend encore pièce fermée, restez sur un robot de table.

**Le Wi-Fi de la résidence bloque l’application.** Revenez au câble USB. Le Bluetooth du mBot et du Codey Rocky ne demande pas la box. Un partage depuis le téléphone couvre un essai Wi-Fi sans toucher au routeur.

**Une vis manque au déménagement suivant.** Le sachet du premier soir est le correctif. Une boîte unique, fermée, avec le câble dedans, aussi.

**L’état des lieux de sortie montre un carton de fils.** S’il n’y a ni trou ni adhésif, le carton part avec vous. La photo du coin vide, prise le jour du départ, sert à en parler calmement.

**Vous vouliez un atelier.** Le bail et la pièce ne le permettent pas encore. La carte CyberPi ou le kit Arduino de table apprennent le code et les capteurs en attendant un logement où un établi a sa place.

## FAQ

### Faut-il un écrit du propriétaire pour un robot qui se range ?

Pour un robot posé ou branché sur une prise existante, l’article 7 de la loi de 1989 n’exige pas d’accord : vous ne transformez pas le local. L’écrit devient nécessaire dès qu’une vis entre dans le mur, dans le meuble loué ou dans le tableau électrique. Un bail plus strict s’applique tel qu’il est signé.

### Un séjour de moins de six mois change-t-il le modèle ?

Oui. Le Penguin Bot à 39,99 € ou le mBot à 89,99 € limitent la somme immobilisée. Le couple Pi 5 plus châssis dépasse 210 € avant l’alimentation. Il se justifie quand vous savez que vous continuerez après le déménagement.

### En colocation, où circule le robot ?

Dans votre chambre, pas dans le couloir commun. Le mètre dégagé se mesure chez vous. Le Codey Rocky évite la négociation sur le passage. Rangez la boîte dans votre placard, pour que personne ne la prenne pour un déchet le jour des poubelles.

### Un aspirateur robot entre-t-il dans ce guide ?

Il se choisit sur la surface, la station et les seuils de porte. Le guide dédié est [l’aspirateur robot à moins de 200 €](/domotique/robot-aspirateur-moins-de-200-euros/). La station reste un objet que vous emportez, elle aussi.

### Que devient la batterie au moment du déménagement ?

Les piles AA sortent du robot. Une batterie lithium suit la notice, et elle voyage avec vous si un transporteur prend le reste des cartons. Le centre d’aide mBot limite la charge USB à 5 V et 1 A.

### Le portail Wi-Fi de la résidence empêche-t-il de programmer ?

Non, tant que vous programmez par USB. C’est le mode de base du mBot, et il existe aussi sur le mBot2, le Codey Rocky et la CyberPi. Le Wi-Fi du logement devient utile plus tard, pour un projet connecté, pas pour le premier mouvement.
