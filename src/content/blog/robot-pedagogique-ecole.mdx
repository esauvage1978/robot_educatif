Choisir un **robot pédagogique** pour une classe n'est pas comme acheter un robot pour la maison : il faut penser **durabilité**, **gestion de parc**, **budget collectivité**, **progression pédagogique** et **formation enseignants**. Ce guide s'adresse aux **enseignants**, **coordonnateurs STEM** et **établissements** qui veulent structurer un projet robotique.

## Critères spécifiques au contexte scolaire

### 1. Robustesse et SAV

En classe :
- **20-30 élèves** vont manipuler le matériel
- **Chocs et chutes** sont fréquents
- Le matériel doit durer **3-5 ans** minimum

Privilégiez :
- **Châssis métallique** ou plastique épais (pas de cardboard)
- **Roues et capteurs remplaçables** facilement
- **SAV réactif** en France
- **Garantie** 1-2 ans minimum

### 2. Évolutivité (cycle 2, 3, 4)

Un bon robot école doit servir :
- **CM1-CM2** : Scratch, défis simples (cycle 3)
- **6e-5e** : Scratch avancé, capteurs (cycle 4)
- **4e-3e** : Python, projets longs (cycle 4)

Évitez les robots « figés » sur une seule tranche d'âge.

### 3. Gestion de parc

Avec 6-12 robots dans un établissement :
- **Charge simultanée** : prévoir multiprises, chargeurs identiques
- **Rangement** : valise / armoire adaptée
- **Mises à jour** : possibilité de flasher en masse
- **Pièces détachées** : stockage centralisé

### 4. Progression pédagogique

Le robot doit s'intégrer :
- Aux **programmes officiels** (BO Technologie, NSI, SNT)
- Aux **séquences existantes** (ne pas tout réinventer)
- Aux **évaluations** (compétences socle commun)

### 5. Budget collectivité

Comptez par robot :
- **Prix unitaire** : 80-180€
- **Accessoires** : 10-30€ (piles, câbles, tapis)
- **Formation** : 0-500€ (selon académie)
- **Maintenance** : 5-10% du prix/an

Pour une classe de 24 élèves (binômes) : **12 robots** = 1000-2500€.

## Financement et subventions

### Sources de financement

1. **Budget établissement** : ligne « matériel pédagogique »
2. **Région/Département** : appels à projets STEM, numérique
3. **Rectorat** : crédits « innovation pédagogique »
4. **Fondations** : La Main à la Pâte, Orange, etc.
5. **Crowdfunding** : parents d'élèves, association

### Monter un dossier

Un bon dossier contient :
- **Projet pédagogique** clair (objectifs, compétences, calendrier)
- **Budget détaillé** (matériel + formation + maintenance)
- **Plus-value** : motivation élèves, lien avec l'entreprise locale
- **Pérennité** : qui maintient le projet après l'année 1 ?

## Gestion pratique en classe

### Organisation (12 robots, 24 élèves)

- **Binômes fixes** : responsabilité du matériel
- **Rotation** : tous les élèves testent tous les robots
- **Chef d'équipe** : élève référent qui explique aux autres
- **Temps tech** : 5 min début/fin de séance pour vérifier le matériel

### Rangement type

1. **Valise mobile** : 6-12 robots, piles, câbles, manuel
2. **Armoire dédiée** : si salle fixe
3. **Étiquettes** : Robot 1, Robot 2, etc. + QR code fiche technique
4. **Fiche incident** : trace les pannes pour SAV

### Éviter les pannes

- **Batteries chargées** : routine fin de séance
- **Câbles USB dédiés** : 1 câble = 1 robot (couleur/étiquette)
- **Firmware à jour** : flash collectif 1×/trimestre
- **Pièces détachées** : roues, capteurs ultrason en stock (×2)

## FAQ enseignants

**Combien de robots pour une classe de 30 ?**  
Idéalement 10-15 robots (binômes/trinômes). Minimum 6 robots (groupes de 5).

**Faut-il un ordinateur par robot ?**  
Non. En Scratch/mBlock, on programme sur 1 PC, puis on uploade sur le robot sans fil.

**Quelle formation pour les enseignants ?**  
1 journée suffit pour mBot. Contactez votre DANE (Délégué Académique au Numérique Éducatif).

**Le matériel est-il compatible entre marques ?**  
Rarement. Choisissez 1 écosystème et restez-y (Makeblock, Arduino, LEGO, etc.).

**Combien de temps dure un robot en classe ?**  
Bien entretenu : 5-7 ans. Remplacer batteries tous les 2-3 ans.

---

**En résumé** : pour l'école, privilégiez des robots **robustes**, **évolutifs** (Scratch + Python) et avec un **écosystème** riche. Le **mBot** (80-100€) est parfait pour CE-CM, le **mBot2** (170€) pour le collège. Prévoyez 1200-3000€ pour équiper une classe selon le niveau. Formez-vous via M@gistère ou La Main à la Pâte, et rejoignez les communautés enseignants pour partager vos séquences.
