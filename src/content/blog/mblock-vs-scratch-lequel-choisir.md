<h2 id="quest-ce-que-scratch">Qu’est-ce que Scratch ?</h2>

**Scratch** est un langage de **programmation visuelle** créé au **MIT** : on assemble des **blocs** pour animer des **lutins** sur une **scène** — jeux, histoires, musique. C’est **très accessible** : pas de syntaxe à taper au début, on raisonne en **séquences**, **boucles**, **conditions**.

- **Pour qui ?** **Débutants** en maternelle / primaire jusqu’à projets plus riches au collège — **logique** avant tout.
- **Où ?** Principalement dans le **navigateur** ([site officiel Scratch](https://scratch.mit.edu/)) ou applications associées.
- **Portée :** millions de projets partagés ; Scratch est **utilisé dans le monde entier** pour l’initiation au code ([présentation Scratch sur Wikipédia](https://fr.wikipedia.org/wiki/Scratch_%28langage%29)).

👉 Pour **créer des jeux** et **animations** sans matériel coûteux, Scratch reste **le meilleur choix pour débuter la programmation** à l’écran.

<h2 id="quest-ce-que-mblock">Qu’est-ce que mBlock ?</h2>

**mBlock** est le **logiciel Makeblock** pour programmer **robots éducatifs** et cartes (**mBot**, **CyberPi**, etc.). L’interface **blocs** est **calquée sur Scratch 3** — on retrouve la même **logique** — mais **mBlock ajoute** :

- les **blocs matériel** (moteurs, **LED**, **capteurs**) ;
- la **connexion** au robot (USB, Bluetooth selon modèle) ;
- le **téléversement** du programme sur la carte ;
- souvent un **passage vers Python** sur les produits compatibles (voir [quel logiciel mBlock](/logiciel-mblock-makeblock-mbot-quel-choisir/)).

C’est donc **plus avancé** que « Scratch seul » dès qu’il s’agit de **faire bouger un vrai objet** — **le meilleur choix pour passer du jeu au code réel** quand un **kit robotique** est sur la table.

**Scratch** reste la **référence** pour enseigner la **logique** sans friction matérielle. **mBlock** est **le meilleur choix pour programmer des robots éducatifs** dans la famille Makeblock — ce n’est pas une « note » plus haute : c’est **l’outil qui va avec le carton**.

<h2 id="selon-objectif">Quel logiciel choisir selon votre objectif ?</h2>

### Choisissez Scratch si…

- l’**enfant débutant** doit **apprendre la logique** (répéter, tester, corriger) **sans acheter de robot** ;
- vous voulez des **jeux** ou **animations** ;
- vous utilisez surtout un **ordinateur ou tablette** et le **partage** de projets sur la communauté MIT.

### Choisissez mBlock si…

- vous avez un **robot éducatif** Makeblock (**mBot**, **Ranger**, **mBot2**…) ;
- vous visez **Arduino / capteurs / moteurs** dans un **atelier STEM** ;
- vous voulez une **progression vers Python** sur une carte prévue pour ça — **un vrai tremplin vers Python** côté « physique ».

**Phrase clé :** **mBlock**, c’est **Scratch-like** pour le cerveau, **Makeblock** pour les mains — **idéal pour apprendre la robotique concrètement**.

<h2 id="mblock-ou-scratch-enfant">mBlock ou Scratch pour un enfant ?</h2>

- **Très jeune, pas de robot :** commencez par **Scratch** — **scratch ou mblock** ne se pose pas encore : tout est à l’écran.
- **Dès qu’un mBot arrive :** basculez sur **mBlock** pour les leçons **robot** ; gardez **Scratch** pour les semaines « création pure » si vous voulez — beaucoup d’écoles font **un trimestre Scratch**, puis **mBlock + kit** l’année suivante : les **concepts** (boucles, messages) se **réutilisent**.

<h2 id="faq">FAQ</h2>

### mBlock est-il mieux que Scratch ?

Pas « mieux » partout : **mieux pour les robots Makeblock**. **Scratch** reste **mieux** pour la **création 100 % écran** et la **communauté** MIT.

### Quel logiciel pour robot éducatif mBot ?

**mBlock** — voir [quel logiciel mBlock](/logiciel-mblock-makeblock-mbot-quel-choisir/).

### Peut-on apprendre Python avec mBlock ?

**Oui** sur matériel et version compatibles (souvent **mBot2** / **CyberPi**) ; complétez avec le [**parcours Python**](/programmation/python/) pour le langage hors robot.

### Scratch est-il suffisant ?

**Oui** pour **jeux** et **animations**. **Non** seul pour **tout** le parcours **Makeblock** : il manque la chaîne **matérielle** que **mBlock** fournit.

### Scratch ou mBlock au collège ?

Souvent **Scratch** en **arts numériques** / **algo** général ; **mBlock** en **club robotique** ou **atelier STEM** avec kits — voir aussi [robots collège dans nos guides budget](/quel-robot-educatif-entre-200-et-500-euros-guide-2026/).
