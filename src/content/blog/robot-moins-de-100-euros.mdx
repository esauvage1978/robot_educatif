## Pourquoi 100€ est le sweet spot

### 1. Qualité sérieuse accessible

**moins de 50€** : qualité **variable**, souvent sacrifices  
**100€** : qualité **solide**, marques reconnues  
**>150€** : qualité premium mais **pas toujours nécessaire**

**100€** = **premier palier qualité pro** sans surpayer.

### 2. Durée de vie longue

**Robot 40€** : dure **1-2 ans** (l'enfant dépasse ou casse)  
**Robot 90€** : dure **3-5 ans** (évolutif, robuste)  
**Robot 170€** : dure **5-7 ans** (mais +70€)

**100€** = **ROI optimal** (retour investissement).

### 3. Ressources et communauté

**Prix ~90€** = **robots populaires** = :
- **Millions** d'utilisateurs (écoles + maisons)
- **Milliers** de tutos YouTube FR
- **Forums** actifs (réponse moins de 24h)
- **Pièces détachées** disponibles

**Robots 40€** = communautés **10× plus petites**.

### 4. Évolutivité réelle

**Robot moins de 100€ bien choisi** grandit avec l'enfant :
- **8 ans** : Scratch, suivre ligne
- **10 ans** : Scratch avancé, défis
- **12 ans** : Python, Arduino C
- **14 ans** : projets perso avancés

**4-5 ans d'usage** vs **1-2 ans** robot cheap.

### 5. Compétences transférables

**Robot ~90€** = **standards industriels** :
- **Scratch** : école primaire/collège
- **Arduino** : lycée STI2D, écoles ingé
- **Python** : data science, web, IA

**Compétences = employabilité**.

## Critères de choix moins de 100€

### 1. Marques reconnues

**Priorité** :
- **Makeblock** (mBot, mBot Ranger) : référence éducation
- **ELEGOO** : excellent rapport qualité-prix Arduino

### 2. Capteurs multiples

**Obligatoires moins de 100€** :
- **Ultrason** : mesure distance, évite obstacles
- **Suiveur de ligne** : capteur IR ou optique
- **LEDs RGB** : retour visuel programmable
- **Buzzer** : sons et mélodies

**Bonus** :
- Capteur lumière
- Télécommande IR
- Gyroscope (rare à ce prix)

**Plus de capteurs** = **plus de projets** = durée vie longue.

### 3. Programmation évolutive

**Idéal moins de 100€** :
- **Scratch/blocs** : démarrage facile
- **+ Arduino C** ou **+ Python** : progression

**Éviter** : Scratch-only (trop limité long terme).

### 4. Ressources françaises abondantes

**Vérifier AVANT achat** :
- **Tutos YouTube FR** : taper « [robot] tutoriel français »
- **Notice FR** : PDF téléchargeable
- **Forum FR** : clubelek.inria.fr, forum.makeblock.com

**mBot** = **champion absolu** ressources FR.

### 5. Extensibilité

**Robot moins de 100€** devrait accepter :
- **Capteurs additionnels** (température, humidité, CO2)
- **Actionneurs** (servo, pince, bras)
- **Modules** (Bluetooth, Wi-Fi pour projets avancés)

**Éviter** : robots **fermés** (impossible ajouter quoi que ce soit).
