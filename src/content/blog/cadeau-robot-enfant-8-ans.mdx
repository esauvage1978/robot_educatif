## Pourquoi 8 ans est l'âge idéal

### 1. Maturité cognitive parfaite

À 8 ans, l'enfant :
- **Lit les consignes** sans aide constante
- **Comprend cause-effet** : « si capteur détecte → alors moteur s'arrête »
- **Supporte l'échec** : « ça ne marche pas, je recommence » (moins de larmes qu'à 6 ans)
- **Explique sa logique** : capable de dire POURQUOI il a mis tel bloc

### 2. Durée d'attention suffisante

**20-40 minutes** par session = parfait pour :
- Assembler le robot (15-20 min)
- Faire un premier programme (10-15 min)
- Tester, corriger, recommencer (10-20 min)

À 6 ans c'était trop court, à 10 ans il veut déjà Python : **8 ans = sweet spot Scratch**.

### 3. Passage CE2-CM1 : période clé

**CE2** : apprentissage multiplication, fractions, résolution problèmes  
→ La **logique de programmation** renforce ces compétences

**CM1** : projets longs, travail de groupe  
→ Le robot peut devenir **projet de classe** ou **activité fratrie**

### 4. Alternative saine aux écrans

Plutôt que YouTube/TikTok passifs :
- **Écran actif** : l'enfant crée, ne consomme pas
- **Manipulation physique** : le robot bouge dans le réel
- **Fierté de montrer** : « regarde ce que j'ai programmé ! »

## Critères de choix pour 8 ans

### 1. Programmation par blocs obligatoire

**Scratch ou équivalent** : glisser-déposer, pas de syntaxe à taper

**Éviter** : Arduino C pur (trop tôt), Python texte (réserver à 10+ ans)

**Idéal** : Scratch + **possibilité Python plus tard** pour que le robot dure 3-5 ans

### 2. Assemblage ni trop simple ni trop complexe

**Trop simple** (10 min, 5 pièces) : frustrant, pas de fierté  
**Trop complexe** (2h, 200 vis) : décourageant si premier robot

**Sweet spot** : **15-30 minutes** avec notice illustrée claire

### 3. Capteurs multiples = projets variés

**Minimum indispensable** :
- **Capteur ultrason** : éviter obstacles, mesurer distance
- **Suiveur de ligne** : parcours au sol
- **LEDs programmables** : retour visuel immédiat

**Bonus** :
- **Buzzer** : sons et mélodies
- **Capteur de lumière** : réagir à l'obscurité
- **Télécommande IR** : contrôle manuel

### 4. Communauté et ressources françaises

Un robot utilisé en **milieu scolaire** = :
- **Tutoriels YouTube** en français
- **Fiches profs** gratuites
- **Forums actifs** pour dépanner
- **Pièces de rechange** faciles à trouver

### 5. Évolutivité (robot qui grandit)

À 8 ans il fait suivre une ligne, à 10 ans il programme en Python, à 12 ans il ajoute un capteur IoT : **rentabiliser l'investissement sur 3-5 ans**.

## Erreurs à éviter

### 1. Acheter trop compliqué

**Erreur** : « Il est intelligent, je prends un kit Arduino avancé »  
**Réalité** : À 8 ans, même très doué, **Scratch d'abord**. Arduino C viendra naturellement à 10-11 ans.

### 2. Oublier les prérequis

**Robot sans ordinateur = objet décoratif**

Vérifier AVANT d'acheter :
- **PC/Mac/tablette** compatible
- **Câble USB** (parfois non fourni)
- **Wi-Fi** (certains robots)
- **Temps adulte** première session (1-2h)

### 3. Négliger les accessoires

Robot seul = **ennui au bout de 2 semaines**

**Indispensables** :
- **Piles rechargeables** (15€) : économie + écologie
- **Tapis parcours** (25€) : défis infinis
- **Livre Scratch** (20€) : autonomie sans écran

### 4. Offrir la veille de Noël sans préparation

**Erreur classique** : déballer le 25 matin, lire notice 1h, chercher piles, installer logiciel, premier test à 14h = frustration

**Solution** :
1. **Recevoir 1 semaine avant** Noël
2. **Assembler en cachette** ou prévoir 1-2h le 25 matin
3. **Installer mBlock** sur PC avant le 24
4. **Charger piles** la veille
5. **Dégager espace** (2m² au sol mini)

### 5. Comparer aux jouets classiques

**Robot ≠ jouet télécommandé**

Un robot éducatif c'est :
- **Apprendre** avant jouer (normal que ça prenne 30 min)
- **Programmer** puis voir le résultat (pas instant)
- **Recommencer** 10× pour réussir (c'est ça le jeu)

Si l'enfant veut **jeu immédiat**, ce n'est pas le bon cadeau.

## Activités clés pour 8 ans

Une fois le robot offert, **quoi faire** ?

### Semaine 1 : Prise en main (3-4 sessions)

**Jour 1** : Assemblage + connexion + LED clignotante  
**Jour 2** : Avancer, reculer, tourner  
**Jour 3** : Boucle infinie (carré, cercle)  
**Jour 4** : Détecter obstacle et s'arrêter

### Semaine 2 : Premiers défis

**Défi 1** : Suivre une ligne au sol (scotch noir)  
**Défi 2** : Éviter 3 obstacles en slalom  
**Défi 3** : Jouer une mélodie (anniversaire, Joyeux Noël)  
**Défi 4** : Parcours chronométré (record familial)

### Mois 1-3 : Projets concrets

**Gardien de chambre** : détecte intrusion, sonne alarme  
**Livreur postal** : suit ligne, s'arrête à destination  
**Danseur** : chorégraphie sur musique  
**Aspirateur** : fait le tour d'une pièce sans tomber

**Ressources** : [Activités mBot rapides](/idees-projets-mbot-rapides-une-heure/) · [Capteur ultrason](/serie-capteur-ultrason-mbot-1-mesurer-distance/)
