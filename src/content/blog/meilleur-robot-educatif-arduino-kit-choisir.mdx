Un **kit robot Arduino** offre une **double découverte** : l'électronique (câblage, capteurs, moteurs) et la programmation en **langage C**. Contrairement aux robots « tout-en-un » comme le mBot, ces kits demandent plus d'assemblage et de compréhension technique — mais ils ouvrent la porte à des **projets infinis** et forment de véritables bases en ingénierie.

Ce guide s'adresse aux **parents et enseignants** qui cherchent un kit pour un enfant d'**au moins 12 ans** ou un ado passionné.

## Qu'est-ce qu'un kit robot Arduino ?

### Les composants typiques

Un kit complet contient :
- Une **carte Arduino** (généralement Arduino UNO R3 ou compatible)
- Un **châssis** de robot (en acrylique ou plastique)
- Des **moteurs DC** avec roues
- Un **driver moteur** (L298N ou similaire)
- Des **capteurs** : ultrason, suivi de ligne, lumière, infrarouge...
- Des **câbles Dupont** et breadboard (ou PCB intégré)
- Souvent : LEDs, buzzer, télécommande IR, module Bluetooth

### Pourquoi choisir Arduino pour un robot ?

✅ **Apprentissage profond** : Comprendre comment fonctionnent les composants  
✅ **Flexibilité totale** : Modifier le code et le hardware à volonté  
✅ **Immense communauté** : Forums, tutoriels, bibliothèques gratuites  
✅ **Prix abordable** : Kits complets entre 35 et 90 €  
✅ **Transition vers le pro** : Arduino est utilisé dans l'industrie et la recherche

❌ **Plus technique** : Nécessite de lire des datasheets et comprendre le câblage  
❌ **Moins "jouet"** : Pas de packaging coloré ni de simplification excessive

## Installation et premiers pas

### 1. Matériel nécessaire

- Le kit Arduino robot de votre choix
- Un **PC Windows, Mac ou Linux**
- Un **câble USB A-B** (fourni avec le kit)
- Des **piles AA rechargeables** (généralement 4 à 6 selon le kit)

### 2. Installer l'IDE Arduino

1. Télécharger l'IDE Arduino sur [arduino.cc](https://www.arduino.cc/en/software)
2. Installer le logiciel (suivre l'assistant)
3. Connecter la carte Arduino en USB
4. Sélectionner le bon port COM dans `Outils > Port`
5. Sélectionner la carte `Arduino UNO` dans `Outils > Type de carte`

### 3. Premier programme : Blink

```cpp
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);
  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}
```

Ce programme fait **clignoter la LED intégrée** de la carte toutes les secondes. C'est le "Hello World" d'Arduino.

### 4. Assembler le robot

Suivre le **manuel du kit** (généralement en PDF ou sur le site du fabricant). Compter **1 à 3 heures** selon le kit et le niveau.

**Conseils** :
- Ne pas forcer les composants
- Vérifier la polarité des piles et des LEDs (+ et -)
- Tester chaque étape avant de passer à la suivante

### 5. Charger le premier exemple robot

Les kits ELEGOO fournissent des exemples de code. Par exemple :
- `01-Forward` : Faire avancer le robot
- `02-Obstacle_Avoidance` : Éviter les obstacles
- `03-Line_Tracking` : Suivre une ligne

Ouvrir le fichier `.ino`, **téléverser** (bouton flèche →), puis **observer** le robot.

## Erreurs fréquentes et solutions

### Le robot ne bouge pas après téléversement

**Causes possibles** :
- Les **piles sont faibles** ou mal insérées
- Le **switch ON/OFF** du robot est sur OFF
- Les **moteurs sont mal câblés** (inverser + et -)

**Solution** : Vérifier les connexions et les piles avec un multimètre.

### Erreur "port COM introuvable"

**Cause** : Les **drivers USB** ne sont pas installés.

**Solution** : Installer les drivers CH340 ou FTDI selon la carte (voir la doc du kit).

### Le robot tourne en rond

**Cause** : Les **moteurs ne tournent pas à la même vitesse** ou un moteur est inversé.

**Solution** : Calibrer les vitesses dans le code ou inverser physiquement un moteur.

### Code ne compile pas

**Causes possibles** :
- **Bibliothèque manquante** (AFMotor, Servo, NewPing...)
- **Erreur de syntaxe** (point-virgule oublié, accolade manquante)

**Solution** : Installer les bibliothèques via `Croquis > Inclure une bibliothèque > Gérer les bibliothèques`.

## FAQ - Kit robot Arduino enfant

### À partir de quel âge un enfant peut-il utiliser Arduino ?

**Minimum 10 ans avec accompagnement**, mais **12 ans est l'âge idéal** pour commencer à coder en C sans frustration. Les plus jeunes (8-10 ans) peuvent utiliser le Penguin Bot avec un adulte.

### Faut-il déjà savoir programmer pour utiliser un kit Arduino ?

**Non**, les kits incluent des **exemples préchargés** et des tutoriels pas à pas. Mais il faut **accepter de lire** (code, documentation) et d'**essayer-échouer-recommencer**.

Pour débuter la programmation, voir [Programmation enfant : à quel âge commencer ?](/programmation-enfant-a-quel-age-commencer/)

### Combien de temps faut-il pour maîtriser Arduino ?

- **1-2 mois** : Comprendre les bases (digitalWrite, analogRead, boucles, conditions)
- **3-6 mois** : Projets autonomes avec plusieurs capteurs
- **1 an+** : Projets complexes (Wi-Fi, IA, multi-fichiers)

### Les kits Arduino sont-ils compatibles entre eux ?

**Oui**, la plupart des capteurs et modules Arduino fonctionnent avec toutes les cartes compatibles UNO. Vous pouvez **mélanger** des composants de plusieurs kits.

### Peut-on utiliser Arduino à l'école / au collège ?

**Absolument**. Arduino est **très utilisé en technologie** au collège et au lycée (programmes officiels). Les kits robots ELEGOO sont parfaits pour des **TP de 2 heures**.

### Arduino vs kits LEGO Mindstorms / Spike ?

| Critère | Arduino | LEGO Mindstorms/Spike |
|---------|---------|------------------------|
| **Prix** | 70-90 € | 350-450 € |
| **Compatibilité** | Capteurs universels | Écosystème LEGO fermé |
| **Programmation** | C/C++ ou Scratch (via extensions) | Scratch ou Python (Spike) |
| **Robustesse** | Moyenne | Excellente |

**Verdict** : LEGO pour l'**école primaire** et les **clubs**. Arduino pour le **collège/lycée** et les **passionnés**.
