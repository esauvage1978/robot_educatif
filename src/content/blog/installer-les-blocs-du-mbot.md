Dans cette partie, nous allons installer les blocs d’instructions du [mBot](https://amzn.to/34eEFtr?tag=manuso06-21). Cette procédure est rapide et très facile à mettre en oeuvre.

Si vous n’êtes pas familiarisé avec mBlock, vous pouvez consulter l’article [Premier pas avec mBlock 5](https://robot-educatif.info/2020/04/07/premier-pas-avec-mblock-5/).

Bien entendu, il faudra adapter la présentation par rapport à votre robot.

![Installer les instructions du mBot](https://robot-educatif.info/wp-content/uploads/2020/04/use1.png)

Ajout d’un appareil

Dans la section **Appareils**, cliquez sur le bouton **ajouter**

![Installer les instructions du mBot, sélection de l'appareil](https://robot-educatif.info/wp-content/uploads/2020/04/use2.png)

Bibliothèque d’appareils

Sélectionnez votre appareil dans la liste

![Installer les instructions du mBot, choix de l'appareil](https://robot-educatif.info/wp-content/uploads/2020/04/use3.png)

Appareil séléctionné

Une fois l’appareil sélectionné, vous pouvez appuyer sur le bouton **OK**

![Installer les instructions du mBot, bloc d'instruction spécifique présente](https://robot-educatif.info/wp-content/uploads/2020/04/use4.png)

Blocs de contrôles

Une fois le robot éducatif sélectionné dans l’ongle **Appareil**, les blocs d’instructions sont maintenant disponibles pour votre robot [mBot](https://amzn.to/34eEFtr?tag=manuso06-21).

Maintenant vous allez pouvoir [écrire votre premier programme](https://robot-educatif.info/2020/04/09/mon-premier-programme-mbot/).

Ou installer des extensions…
