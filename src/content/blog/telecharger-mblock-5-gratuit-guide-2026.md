<h2 id="windows">2. Installer mBlock 5 sur PC Windows 10 et Windows 11</h2>

**Prérequis rapides :** connexion Internet pour le téléchargement (~380 Mo), compte **administrateur** Windows (ou un adulte qui peut cliquer sur **Oui** à l’UAC), environ **1,5 à 2 Go** libres sur le disque système.

1. **Téléchargez l'exécutable officiel** (`V5.6.x.exe` environ 380 Mo) dans la rubrique **mBlock PC version → Download for Windows** de la page officielle Makeblock.
2. **Lancez le fichier `.exe`** depuis votre dossier *Téléchargements* (`Ctrl + J` dans Chrome, Edge ou Firefox).

![Capture d’écran : Explorateur Windows — installateur mBlock dans Téléchargements](/capture/installer-mblock-5-sous-windows-10/explorateur_telechargement.png)

*Double-cliquez sur le fichier `.exe` que vous venez de télécharger. Crédit : Emmanuel Sauvage, Robot Éducatif — octobre 2026.*

3. **Validez le contrôle Windows (UAC)** — le **contrôle de compte utilisateur** affiche « Voulez-vous autoriser cette application à apporter des modifications à votre appareil ? » — cliquez **Oui**. Sans droits admin, demandez de l’aide ou basculez sur <a href="/mblock-en-ligne-programmer-sans-installer/">mBlock en ligne</a>.
4. **SmartScreen** : si Windows affiche *« Windows a protégé votre ordinateur »*, cliquez **Informations complémentaires** puis **Exécuter quand même** uniquement si l’éditeur affiché est **Makeblock** et que le fichier provient de [mblock.cc](https://www.mblock.cc/en-us/download/).
5. **Progression** : les installateurs récents copient les fichiers dans `Program Files` sans assistant intermédiaire ni logiciel publicitaire.

<h2 id="pilote-ch340">3. Pilote USB mBot (CH340) : l'étape clé à ne pas fermer</h2>

À la fin de l'installation de mBlock 5, une petite fenêtre intitulée **Driver Setup (CH340 / CH341SER)** s'ouvre par-dessus l'installateur :

- Cliquez sur **Install** (ou *Installer*) et attendez le message *Driver install success*.
- Le **CH340** est une puce USB-série courante sur la carte **mCore du mBot** ; ce pilote est indispensable pour que Windows ou macOS reconnaisse le robot ou une carte **Arduino UNO / Nano** sur un port série (`COM3`, `COM4`, etc.).
- **Aucune inscription obligatoire** : lorsque mBlock 5 s'ouvre, vous n'avez pas besoin de créer de compte pour programmer, enregistrer vos fichiers `.mblock` sur votre disque dur ou téléverser vers le robot.

<h2 id="macos">4. Installation sur Mac (macOS), Linux et Chromebook</h2>

- **Sur Mac** : ouvrez le fichier `.dmg` ou `.pkg` téléchargé, glissez l'icône **mBlock** dans le dossier **Applications**. Au premier lancement, si macOS bloque l'ouverture, allez dans **Réglages Système → Confidentialité et sécurité → Ouvrir quand même**.
- **Sur Linux (Ubuntu, Debian, Raspberry Pi OS)** : pour programmer facilement en salle informatique ou sur un poste léger, privilégiez la version navigateur avec le pont série **mLink** Linux (voir [mBlock en ligne](/mblock-en-ligne-programmer-sans-installer/)).
- **Sur Chromebook** : pas d’installateur `.exe` ; utilisez [mBlock en ligne](/mblock-en-ligne-programmer-sans-installer/) et **mLink** dans Chrome.

<h2 id="apres-telechargement">6. Passer mBlock 5 en français et brancher le mBot</h2>

1. **Mettre mBlock 5 en français** : cliquez sur l'icône **globe terrestre** en haut à gauche de la barre de menu et sélectionnez **Français**.
2. **Sélectionner votre robot** : dans l'onglet **Appareils** (en bas à gauche), cliquez sur **+ Ajouter**, choisissez **mBot** (ou **CyberPi / mBot2**), puis cliquez sur **OK**.
3. **Connecter en USB** : allumez le robot, branchez le câble USB, cliquez sur **Connecter** et validez le port `COM` détecté.
4. **Tester un premier script** : suivez nos guides [Premiers pas avec mBlock 5](/premier-pas-avec-mblock-5/) et [Installer les blocs du mBot](/installer-les-blocs-du-mbot/).

<h2 id="faq">9. FAQ Téléchargement mBlock 5</h2>

### Où télécharger mBlock 5 gratuitement en français ?
Rendez-vous sur la page officielle **mblock.cc/en-us/download**, choisissez **mBlock PC version** (Windows ou Mac) et lancez l'installateur. L'interface bascule en français via l'icône globe en haut à gauche.

### Faut-il créer un compte pour utiliser mBlock 5 ?
**Non.** L'utilisation hors ligne, l'enregistrement de projets sur l'ordinateur et le téléversement USB vers un mBot ou mBot2 fonctionnent sans compte ni inscription.

### Comment installer le pilote USB CH340 du mBot en 3 minutes ?
Cochez ou validez la fenêtre **Setup_Driver_CH341** qui s'affiche automatiquement à la fin de l'installation de mBlock 5. Cliquez sur **Install** : votre robot sera reconnu sur un port COM dès le premier branchement USB.

Ouvrez directement **[ide.mblock.cc](https://ide.mblock.cc/)** (mBlock 5 en ligne), ou suivez notre guide pour <a href="/mblock-en-ligne-programmer-sans-installer/">programmer avec mBlock en ligne sans rien installer</a> depuis Chrome ou Edge.

### Quelle est la différence entre mblock.cc et ide.mblock.cc ?
**mblock.cc/download** sert à **télécharger** l’application bureau mBlock 5 (Windows / Mac). **ide.mblock.cc** est l’**IDE** (environnement de développement intégré) **mBlock 5 en ligne** : vous programmez dans le navigateur, sans installer les ~380 Mo.

### mBlock 5 est-il vraiment gratuit ?
Oui. L’installateur officiel Makeblock et la version navigateur sont gratuits. Évitez les sites miroirs et les liens « crack » : utilisez uniquement [la page Download Makeblock](https://www.mblock.cc/en-us/download/) ou [ide.mblock.cc](https://ide.mblock.cc/).
