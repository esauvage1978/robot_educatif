<h2 id="en-une-minute">En une minute</h2>

- **mBlock 5** = logiciel **Makeblock** pour programmer en **blocs** (esprit **Scratch**), brancher des **robots** (mBot, mBot2, Codey Rocky, CyberPi…) et parfois passer en **Python**.
- **Téléchargement** = **gratuit** sur **mblock.cc** ; versions **Windows**, **Mac**, **Linux** selon votre machine.
- **Sans installation** = **mBlock Web** dans le navigateur — pratique, avec quelques limites pour le **Bluetooth** ou le **firmware** selon les cas.
- **Après install** : ajoutez votre **appareil** dans mBlock, chargez les **extensions** mBot si besoin, puis enchaînez avec un <a href="/mon-premier-programme-mbot/">premier programme</a>.

Le seul endroit fiable pour **« télécharger mblock »** ou **« mblock 5 download »** sans mauvaise surprise : le site **Makeblock**.

- **Ne téléchargez pas** mBlock depuis des sites « mirror », forums ou boutons publicitaires : risque de version périmée ou de bundle indésirable.
- Sur la page de téléchargement, le site propose en général **plusieurs OS** : repérez l’icône **Windows**, **Apple** ou **Linux** selon votre ordinateur.
- **Taille** : comptez souvent **plusieurs centaines de Mo** pour l’installateur et **≈1 à 2 Go** une fois installé (ordre de grandeur — voir aussi notre <a href="/installer-mblock-5-sous-windows-10/">guide Windows détaillé</a>).

<h2 id="windows">Windows (10 et 11)</h2>

1. Ouvrez <a href="https://www.mblock.cc/fr-fr/download/">mblock.cc</a> → section **Windows** → téléchargez l’installateur (**64 bits** dans la plupart des cas).
2. Ouvrez le fichier **.exe** dans **Téléchargements**, acceptez l’**UAC** (**Oui**).
3. Sur les installateurs récents, la **copie des fichiers** démarre vite ; à la fin : **Terminer**, puis lancez **mBlock** depuis le bureau ou le menu Démarrer.

**Guide détaillé** (captures, SmartScreen, antivirus) : <a href="/installer-mblock-5-sous-windows-10/">Installer mBlock 5 sous Windows 10/11</a> — même procédure pour **Windows 11** avec des repères spécifiques dans <a href="/installer-mblock-windows-11-guide-facile/">ce court article</a>.

<h2 id="macos">macOS</h2>

1. Téléchargez le paquet prévu pour **macOS** sur la même page officielle.
2. Ouvrez le **.dmg** ou l’installateur, glissez **mBlock** dans **Applications** si demandé.
3. Au premier lancement, macOS peut afficher un avertissement de sécurité : ouvrez **Réglages système → Confidentialité et sécurité** pour autoriser l’application **signée** Makeblock, ou faites **clic droit → Ouvrir** sur la première exécution.

<h2 id="linux-chromebook">Linux et Chromebook</h2>

- **Linux** : une version est souvent proposée sur **mblock.cc** (format selon la période — suivez la doc Makeblock pour votre distribution).
- **Chromebook** : selon modèle et politique d’école, on combine parfois **mBlock Web** et outils complémentaires ; en cas de doute, privilégiez la **version en ligne** pour les ateliers courts.

<h2 id="mblock-explique">mBlock : logiciel de programmation (Scratch + robots)</h2>

- **Scratch** (MIT) est pensé surtout pour des **projets à l’écran** et le partage communautaire.
- **mBlock** reprend l’**esprit blocs** et ajoute tout l’**écosystème Makeblock** : cartes, **moteurs**, **capteurs**, **téléversement**.
- Sur certains modèles, un mode **Python** permet de poursuivre en **texte** — utile au collège / lycée quand les blocs sont maîtrisés.

Pour une comparaison pédagogique Scratch vs mBlock : <a href="/mblock-vs-scratch-lequel-choisir/">mBlock vs Scratch : lequel choisir ?</a>
