<p><strong>Raspberry Pi ou kit robot pour un ado ?</strong><br>
Entre <strong>12 et 15 ans</strong>, tranchez selon ce que l’ado veut <strong>montrer en premier</strong> : un <strong>robot qui roule</strong> (motivation immédiate, capteurs embarqués) ou une <strong>plateforme Linux</strong> (Python large, caméra, domotique, serveur). Ce n’est pas « l’un meilleur que l’autre » : l’enjeu est le <strong>temps adulte</strong>, l’<strong>autonomie</strong> et le <strong>projet</strong> cadré.</p>

<p><strong>Résumé :</strong> le robot cible la <strong>robotique guidée</strong> ; la Pi cible la <strong>variété logicielle</strong> — les parcours peuvent se rejoindre (Pi dans un châssis) une fois les bases posées.</p>

<p>Ce guide s’appuie sur des <strong>usages maker et collège</strong>, la <strong>documentation des écosystèmes</strong> Makeblock et Raspberry Pi, et des <strong>retours familles</strong> sur la charge de configuration — <strong>2026</strong>.</p>

<h2 id="decision">1. Tableau de décision rapide</h2>

| Critère | Raspberry Pi | Kit robot (mBot2, etc.) |
|---------|--------------|-------------------------|
| **Premier « wow »** | Plus tard (écran, config) | Souvent **rapide** (roule, évite) |
| **Variété des projets** | Très large (serveur, caméra, domotique) | Centrée **robotique / capteurs embarqués** |
| **Charge pour l’adulte** | Système, SD, mises à jour | Installation logicielle + parfois Bluetooth |
| **Python** | Natif, énorme communauté | Selon modèle (ex. mBot2, CyberPi — voir comparatifs) |
| **Linux / ligne de commande** | Au cœur du projet | Souvent **secondaire** |

<h2 id="choisir-pi">2. Choisir Raspberry Pi quand…</h2>

- L’ado veut **héberger des services**, creuser le **réseau**, la **caméra**, le **shell**, ou faire du **Python** sans se limiter au robot.
- Vous acceptez les étapes **système** (carte SD, mises à jour) — notre [mise en route Raspberry Pi 3](/mise-en-route-raspberry-pi-3-modele-b/) reste une base utile même si les modèles ont évolué.

En prolongement : [comparatif Pi 3 / 4 / 5](/raspberry-pi-3-vs-4-vs-5-comparatif-2026/), [Pi 4 quelle mémoire](/raspberry-pi-4-quelle-version-memoire-acheter/).

<h2 id="choisir-robot">3. Choisir un kit robot quand…</h2>

- L’objectif affiché est **« faire rouler quelque chose »** et **filmer** ou **montrer** un projet à la famille.
- Vous visez **Scratch → Python** dans un environnement **guidé** : [mBot2](/mbot2-de-makeblock-le-robot-educatif-pour-apprendre-la-robotique/), ou une carte **Makeblock** [CyberPi](/decouvrez-makeblock-cyberpi-une-carte-de-developpement-electronique-polyvalente/) pour un entre-deux — voir aussi [mBot2 vs CyberPi](/mbot2-vs-cyberpi-comparatif/).

<h2 id="mix">4. Le mix « Raspberry dans un châssis »</h2>

Monter une **Pi** dans un **robot** avec moteurs et capteurs, c’est passionnant mais **plus long** à stabiliser qu’un robot « prêt à l’emploi ». Pour un **premier** achat, tranchez selon la **patience** et le **goût du bricolage système**. Les deux mondes peuvent **cohabiter** plus tard si le projet dure.

<h2 id="notre-recommandation">5. Notre recommandation</h2>

<p><strong>Meilleure entrée « robot visible » :</strong> kit <strong>documenté</strong> type <strong>mBot2</strong> ou équivalent avec tutoriels suivis.</p>

<p><strong>Meilleure entrée « Linux et projets variés » :</strong> <strong>Raspberry Pi 4 (4 Go)</strong> ou <strong>Pi 5 (4 Go)</strong> selon budget, avec refroidissement et alim sérieux — voir les guides RAM.</p>

<p><strong>Critères express :</strong> motivation (court terme vs long terme) ; PC et écran dispos ; temps adulte pour SD et mises à jour.</p>

<h2 id="faq">6. FAQ</h2>

<h3 id="faq-pi-robot">6.1. Raspberry Pi ou kit robot pour un ado ?</h3>

<p>Robot pour le mouvement guidé ; Pi pour Linux, serveur et projets larges — le tableau ci-dessus résume les arbitrages.</p>

<h3 id="faq-cyberpi">6.2. La CyberPi remplace une Raspberry ?</h3>

<p>Non : écosystème Makeblock et mBlock, pas serveur Linux généraliste.</p>

<h3 id="faq-les-deux">6.3. L’ado veut les deux : par quoi commencer ?</h3>

<p>Souvent le robot si la motivation est faible ou irrégulière ; la Pi si les sessions longues devant un tutoriel sont déjà possibles.</p>

<h3 id="faq-chassis">6.4. Pi dans un châssis dès le début ?</h3>

<p>Réservé aux profils patients ou en second projet — plus de réglages qu’un kit clé en main.</p>
