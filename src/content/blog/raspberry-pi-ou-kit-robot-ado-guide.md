Vers **12–15 ans**, deux chemins se croisent souvent : la **carte programmable** type **Raspberry Pi** (projets variés, Linux, Python « pur ») et le **robot éducatif** (motivation immédiate, mouvement, capteurs). Ce n’est pas le même investissement en **temps adulte** ni le même **niveau d’autonomie** — et ce n’est pas non plus « l’un mieux que l’autre » : ça dépend de ce que l’ado veut **montrer** en premier.

![Plateforme large versus produit robot prêt à l’emploi](/images/blog/guides-2026/raspberry-vs-kit-robot.svg)

## 1. Tableau de décision rapide

| Critère | Raspberry Pi | Kit robot (mBot2, etc.) |
|---------|--------------|-------------------------|
| **Premier « wow »** | Plus tard (écran, config) | Souvent **rapide** (roule, évite) |
| **Variété des projets** | Très large (serveur, caméra, domotique) | Centrée **robotique / capteurs embarqués** |
| **Charge pour l’adulte** | Système, SD, mises à jour | Installation logicielle + parfois Bluetooth |
| **Python** | Natif, énorme communauté | Selon modèle (ex. mBot2, CyberPi — voir comparatifs) |
| **Linux / ligne de commande** | Au cœur du projet | Souvent **secondaire** |

## 2. Choisir Raspberry Pi quand…

- L’ado veut **héberger des services**, creuser le **réseau**, la **caméra**, le **shell**, ou faire du **Python** sans se limiter au robot.
- Vous acceptez les étapes **système** (carte SD, mises à jour) — notre [mise en route Raspberry Pi 3](/mise-en-route-raspberry-pi-3-modele-b/) reste une base utile même si les modèles ont évolué.

## 3. Choisir un kit robot quand…

- L’objectif affiché est **« faire rouler quelque chose »** et **filmer** ou **montrer** un projet à la famille.
- Vous visez **Scratch → Python** dans un environnement **guidé** : [mBot2](/mbot2-de-makeblock-le-robot-educatif-pour-apprendre-la-robotique/), ou une carte **Makeblock** [CyberPi](/decouvrez-makeblock-cyberpi-une-carte-de-developpement-electronique-polyvalente/) pour un entre-deux — voir aussi [mBot2 vs CyberPi](/mbot2-vs-cyberpi-comparatif/).

## 4. Le mix « Raspberry dans un châssis »

Monter une **Pi** dans un **robot** avec moteurs et capteurs, c’est passionnant mais **plus long** à stabiliser qu’un robot « prêt à l’emploi ». Pour un **premier** achat, tranchez selon la **patience** et le **goût du bricolage système**. Les deux mondes peuvent **cohabiter** plus tard si le projet dure.

## 5. Mini-FAQ

**L’ado veut les deux : par quoi commencer ?**  
Souvent le **robot** si la motivation est **faible** ou intermittente ; la **Pi** si elle/il tient déjà des sessions longues devant un tutoriel.

**CyberPi remplace une Raspberry ?**  
Non : la CyberPi est une **carte Makeblock** avec écosystème mBlock — proche du robotique Makeblock, pas d’un serveur Linux généraliste.
